```unknown
## 1. competition（竞争格局）

### 完整格式
```
⚔️ 全球厂商|份额%|备注, 全球厂商|份额%|备注||中国：厂商|份额%|备注, 厂商|份额%|备注|🔒 壁垒项：说明|壁垒项：说明|📐 维度：说明|维度：说明
```

### 分段语法

| 段 | 分隔符 | 含义 | 必填 |
|----|--------|------|:--:|
| 全球市场 | `,` 分隔厂商 | `厂商名\|份额%\|备注` | ✅ |
| 中国市场 | `\|\|` 前导 | `中国：厂商名\|份额%\|备注` | - |
| 进入壁垒 | `🔒` 前导 | `壁垒项：说明`，`\|` 分隔多项 | - |
| 技术代差 | `📐` 前导 | `维度：说明`，`\|` 分隔多项 | - |

### 厂商行格式
```
厂商名|份额%|备注说明
```

- 份额%：纯数字或 "~XX%"，不带空格
- 备注：简述核心竞争力，≤80字
- 中国市场需以 `中国：` 开头

### 示例

```
⚔️ NVIDIA|86%|数据中心AI GPU绝对垄断, AMD|8%|MI300X追赶（ROCm生态差距大）, Intel|3%|Gaudi 3转型中||中国：华为昇腾|-|910B国产替代主力（7nm）, 壁仞科技|-|BR100受限产能+制裁|🔒 CUDA生态锁定效应极强（300万+开发者，15年积累，替代成本极高）|先进制程+CoWoS封装（中国受限5nm以下制程）|📐 制程工艺：7nm vs 台积电3nm（差距5-8年）|生态差距：CUDA不可替代性远超硬件差距（10年+）
```

## 2. key_trends（关键趋势）

### 格式
```
1) 趋势标题——趋势描述|2) 趋势标题——趋势描述|3) ...
```

### 规则
- 用 `|` 分隔不同趋势
- 用 `——`（两个全角破折号）分隔标题和描述
- 标题 ≤40字，描述 ≤140字
```
