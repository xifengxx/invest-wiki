# AI Agent

> **AI算力** · L4 · TAM **$11B** · CAGR **50%**

AI Agent是能**自主感知环境、制定计划、使用工具、执行多步骤任务**的智能体——与聊天机器人不同，Agent可调用API、读写文件、操作软件完成复杂工作流。|**2025是Agent元年**：OpenAI Agents SDK、Anthropic Claude Code($1B ARR/6个月)+Computer Use、Google Mariner、Microsoft Copilot Agents发布。MCP协议(Linux基金会)成为Agent-工具交互行业标准，获OpenAI/Google/Microsoft联合采用。|**Gartner预计2026年40%企业应用嵌入Agent**(2025年<5%)。Agent成本$0.25-0.50/interaction vs 人工$3-6。垂直Agent(Harvey法律/Sierra客服/Devin编程)在专业领域超越通用Agent。
