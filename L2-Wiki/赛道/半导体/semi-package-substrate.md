# 封装基板材料

> **半导体** · L1 · TAM **$5B** · CAGR **12%**

封装基板是连接芯片与PCB的**「桥梁」**——承担电气连接、机械支撑和散热功能。**ABF（Ajinomoto Build-up Film）是FC-BGA基板的核心绝缘材料**，由日本味之素独家供应（>95%全球份额）。|**AI芯片驱动封装基板层数从14层增加到20+层**，线宽/线距从15/15μm向8/8μm推进。封装基板是仅次于硅片的第二大半导体材料市场。|**味之素ABF膜是FC-BGA产能的最大瓶颈**——ABF扩产速度跟不上AI芯片需求增长，供给短缺预计持续至2028+。全球FC-BGA产能集中在台湾（Unimicron #1）和日本（Ibiden/Shinko），中国深南电路（002916）和鹏鼎控股（002938）正在从传统PCB向FC-BGA转型。
