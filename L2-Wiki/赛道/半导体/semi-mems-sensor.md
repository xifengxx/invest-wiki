# MEMS传感器

MEMS（微机电系统）传感器是将机械结构与电子电路集成在硅片上的微型传感器，涵盖惯性传感器（加速度计/陀螺仪）、麦克风、压力传感器、环境传感器等。智能手机、汽车自动驾驶和AI终端是三大核心应用，推动MEMS从单一传感器走向多传感器融合。
