# HVDC高压直流供电 · 数据中心供电架构的直流革命

> **数据中心供电架构从交流(AC)向高压直流(DC)革新——PUE降至1.1以下，2035年30%新建AIDC采用HVDC+绿电架构** | 技术 · 中级

---

## 一、生活化类比：直流快充vs交流慢充——数据中心供电也到了"换直流"的时候

你有一辆电动车。如果用家里的交流充电桩（AC慢充），充电流程是：电网的交流电→车载充电机把交流变直流→电池。中间至少经过3-4次交直流转换，每次转换都有5-10%的能量损耗，最终只有约85%的电力真正充进了电池。

如果你用直流快充桩（DC快充），充电流程是：电网的交流电→充电桩内部一次性把交流变直流→直接充进电池。中间只经过1次转换，能量损耗大幅降低，95%以上的电力进了电池。而且直流快充功率更大，充电时间从8小时缩短到30分钟。

这就是传统数据中心供电架构（AC UPS方案）和HVDC（高压直流供电）的差异。

传统数据中心：市电交流→UPS把交流变直流存进电池→再变回交流→送到服务器电源→服务器电源再把交流变直流→给GPU/CPU供电。整个链路"AC→DC→AC→DC"，经过4次转换，每次转换损耗3-5%，总损耗高达15-20%。这就是为什么传统数据中心PUE（电能使用效率）通常在1.4-1.6——每1度电用在计算上，还要额外花0.4-0.6度电维持供电和散热。

HVDC方案：市电交流→一次性变直流（240V/336V高压DC）→直接配送至服务器→服务器电源只需简单DC-DC降压→给GPU/CPU供电。链路变为"AC→DC→DC"，仅2次转换，少了一半的转换环节。总损耗降至8-10%以下，PUE可降至1.1以下。

**对应关系：**

| 比喻中的元素 | 对应的技术/产业元素 |
|-------------|------------------|
| 交流慢充（多次转换） | 传统AC UPS供电架构（4次交直流转换） |
| 直流快充（一次转换到底） | HVDC高压直流供电架构（2次转换） |
| 充电效率85% vs 95% | PUE 1.4-1.6 vs PUE<1.1 |
| 车载充电机 | 传统UPS+服务器电源的多级转换 |
| 直流充电桩 | HVDC整流器+直流配电柜 |
| 电池（最终用户） | GPU/CPU/存储（IT负载） |
| 充电时间8小时vs30分钟 | 同等IT负载下电力基础设施投资降低20-30% |

## 二、专业但通俗的定义

**全称**：High Voltage Direct Current（HVDC），高压直流供电。在数据中心配电架构中，市电引入后一次性整流为240V或336V的高压直流电，通过直流母线直接配送至服务器机柜，服务器电源仅需做一次DC-DC降压即可为芯片供电。相比传统AC UPS方案少了两级交直流转换，能量损耗降低40-50%。

**传统AC UPS方案 vs HVDC方案：**

| 对比维度 | 传统AC UPS方案 | HVDC高压直流方案 |
|---------|--------------|-----------------|
| 供电链路 | AC→DC(UPS整流)→AC(UPS逆变)→DC(服务器PSU)=4次转换 | AC→DC(HVDC整流)→DC(服务器DC-DC)=2次转换 |
| 转换效率 | 每级3-5%损耗，总损耗15-20% | 总损耗8-10%，节省50% |
| PUE | 1.4-1.6（每1W IT负载需1.4-1.6W总功率） | <1.1（接近理想值1.0） |
| 供电可靠性 | 单UPS故障需切换到备用UPS（毫秒级中断风险） | 直流母线可直接并联电池，无切换中断 |
| 设备体积 | UPS+配电柜+蓄电池室占用大量空间 | 设备数量减少40%+，节省机房面积 |
| 与绿电/储能的兼容性 | 光伏/储能输出为直流，需逆变后再整流（多两次转换） | 光伏/储能直流输出可直接接入直流母线（零额外转换） |
| 运维复杂度 | 需管理UPS的逆变器/旁路/同步等复杂系统 | 拓扑简化，运维工作量降低50%+ |

**核心优势：**
1. **转换环节减半，能效提升40-50%**：4次转换→2次转换，PUE从1.5降至1.1以下，以10MW数据中心测算年省电费超1000万元
2. **天生兼容光伏+储能**：光伏板和储能电池输出都是直流电，HVDC架构下可直接接入直流母线，省去DC→AC→DC的两次无效转换
3. **可靠性更高**：直流电没有频率和相位问题，多路电源可直接并联运行，避免交流UPS的同步和环流问题
4. **设备简化和空间节省**：取消UPS逆变器和服务器AC-DC前端，设备数量和机房占用面积减少40%+

## 三、为什么市场会关注它

| 维度 | 具体依据 |
|-----|---------|
| **政策驱动** | 中国"东数西算"工程要求新建数据中心PUE<1.25（东部<1.2），HVDC是实现该目标的标配技术；工信部《新型数据中心发展三年行动计划》明确推广HVDC |
| **技术突破** | 336V HVDC标准成熟(中国移动/电信已大规模部署)；NVIDIA GB300系列AI服务器支持HVDC直流输入；华为/维谛240V HVDC市占率领先 |
| **海外映射** | Google/Meta自建数据中心已全面采用HVDC+锂电备电方案，PUE<1.1；OpenAI Stargate超算中心规划全面采用HVDC架构 |
| **产业链传导** | AI训练/推理功耗激增→单机柜功率从5kW升至50kW+→传统AC UPS无法经济支撑→HVDC+液冷成为AIDC标配→供电设备/液冷/服务器电源全链条升级 |
| **订单/业绩驱动** | 全球数据中心年耗电达1.5万亿度(2025)，AI数据中心占比超20%且快速增长；2035年全球30%新建AIDC采用HVDC+绿电架构，相关市场规模超500亿美元 |

## 四、产业链位置

| 产业链环节 | 主要作用 | 代表公司/板块 | 小白理解 |
|-----------|---------|-------------|---------|
| 上游（HVDC整流设备） | 将市电AC整流为240V/336V DC，是HVDC系统的核心设备 | 维谛技术(Vertiv)、施耐德、台达电子、中恒电气 | 直流快充桩的"变压器+整流器" |
| 中游（直流配电系统） | 高压直流母线的配电柜、开关、保护装置 | 维谛技术、施耐德、正泰电器 | 家里的配电箱，但更高压、更智能 |
| 中游（服务器直流电源） | 接受240V/336V直流输入，DC-DC降压输出12V/48V给主板 | 台达电子、光宝科技、长城电源 | 服务器的"消化系统"——把高压直流变成芯片能吃进去的低压 |
| 下游（数据中心运营） | AIDC/HVDC数据中心的设计建设和运营 | Google、Meta、Microsoft、国内三大运营商、万国数据 | 真正用电的人——享受省电和省空间的好处 |
| 配套（绿电光伏+储能） | 光伏+储能直接接入HVDC直流母线，零额外转换损耗 | 宁德时代、比亚迪、隆基绿能 | 给直流快充桩拉了一根专属的太阳能供电线 |

> HVDC位于AI算力 **L3 基础设施层的供电环节**——它不直接提升AI性能，但决定了AI算力能否经济地、可持续地运行。一台GPU少1%的供电损耗，放在10万卡集群就是几百万元的电费差异。

## 六、投资关注点

1. **AIDC新建项目HVDC渗透率**：从当前约15%的新建数据中心采用HVDC，向30%+渗透的速度(2026-2028关键窗口期)
2. **NVIDIA GB300系列HVDC适配进度**：NVIDIA推动AI服务器原生支持HVDC直流输入，将HVDC从"数据中心级方案"升级为"服务器级标准"，大幅加速渗透
3. **光伏+储能+HVDC"光储直柔"一体化方案**：这是HVDC的终极形态——绿电直流直供IT负载，零逆变损耗，华为/维谛的方案落地项目数和规模
4. **运营商HVDC集采规模**：三大运营商(中国移动/电信/联通)是HVDC最大单一采购方，季度集采量和价格走势
5. **液冷+HVDC的协同渗透**：高密度AI服务器(50kW+/柜)必须液冷+HVDC搭配使用，两者的协同部署比例是AIDC成熟度的关键指标

## 七、风险提示

| 风险 | 如果发生，会怎样 |
|-----|----------------|
| 传统UPS技术迭代延缓HVDC渗透 | UPS厂商推出超高效率AC方案(99%转换效率)，缩小与HVDC的能效差距→HVDC的性价比优势减弱→客户停留在AC方案 |
| 标准不统一导致生态碎片化 | 240V/336V/48V等多种HVDC电压标准并存→设备互不兼容→客户观望→产业链规模效应无法形成 |
| 直流配电安全标准滞后 | 高压直流电的灭弧/接地保护标准不完善→安全事故发生→监管收紧→HVDC部署审批变慢 |
| 光伏+储能的HVDC直供方案技术不成熟 | 光伏功率波动+储能充放电对直流母线电压稳定性的冲击难以克服→光储直柔方案迟迟无法商用→HVDC停留在"省电"而非"零碳"维度 |
| AI算力需求增长放缓 | AI投资退潮→新建数据中心骤减→HVDC设备需求断崖式下跌→相关公司收入和估值双杀 |

## 八、如何判断是真逻辑还是炒概念

| 判断维度 | 应该看什么 | 小白容易误判的地方 |
|---------|-----------|------------------|
| 是否有HVDC产品的规模中标和实装 | 公司是否在运营商/云厂商的HVDC集采中标，中标金额和市场份额 | 把"有HVDC产品"当"HVDC产品卖得好" |
| 传统UPS收入占比是否过高 | UPS收入占比>60%的公司做HVDC，是左右手互搏 | 以为"既有UPS又有HVDC"是双保险而非结构风险 |
| HVDC产品是否匹配电压标准 | 240V(中国主流) vs 336V(国际趋势)，产品能否对应目标市场 | 以为一个HVDC产品能吃遍全球市场 |
| 客户是否顶级 | 是否进入Google/Meta/AWS/三大运营商HVDC供应链 | 把"给中小企业做过HVDC项目"当"进入了顶级客户供应链" |
| 与液冷/光伏的协同能力 | 是否具备HVDC+液冷+光伏储能的系统级方案能力（而非单一设备） | 以为能卖一个整流器就能做AIDC全栈供电 |
