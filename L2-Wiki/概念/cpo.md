# CPO共封装光学 · 光引擎与交换芯片的集成革命

> **将光引擎集成到交换机ASIC封装内部，消除传统可插拔光模块的电气损耗——2026年从实验室走向规模商用** | 技术 · 高级

---

## 一、生活化类比：把发动机装进车身里——从外挂光模块到内置光引擎

传统数据中心网络设备的工作方式，就像一辆发动机外挂在车架外面的汽车：发动机（光模块）装在车身外面，通过一根长长的传动轴（PCB铜走线）把动力传到车轮（交换芯片）。传动轴越长，能量损耗越大，油耗（功耗）越高，而且传动轴本身占地方、容易坏。

这就是传统可插拔光模块(Pluggable Optics)的运作方式：光模块通过交换机面板上的端口插入，光信号在光模块里完成光电转换后，变成电信号，再通过5-10厘米长的PCB铜走线传输到交换芯片。这段长距离的铜走线会导致信号严重衰减，因此需要在光模块里塞一个DSP芯片（数字信号处理器）来补偿信号损失——就像在传动轴上装一个笨重的变速箱来弥补动力损耗。而这个DSP正是光模块功耗的最大来源（占比超过50%）。

CPO的做法，是把光引擎（完成光电转换的核心器件）直接集成到交换机ASIC芯片的封装基板上——就像把发动机直接装进车身，紧贴着车轮。传动轴短到几乎没有，变速箱（DSP）可以大幅简化甚至取消。整辆车更轻、更快、更省油。

**对应关系：**

| 比喻中的元素 | 对应的技术/产业元素 |
|-------------|------------------|
| 发动机外挂在车架外面的汽车 | 传统可插拔光模块（Pluggable Optics） |
| "发动机装进车身"的集成设计 | CPO共封装光学方案 |
| 长传动轴 | 交换机PCB上的铜走线（5-10cm电信号路径） |
| 笨重的变速箱 | DSP数字信号处理器（功耗占光模块50%+） |
| 发动机本体 | 硅光子光引擎（PIC，光子集成电路） |
| 紧贴着发动机的车架 | 交换机ASIC的先进封装基板 |
| 油耗（能量损耗） | 光互连功耗（占交换机总功耗30%+） |

## 二、专业但通俗的定义

**全称**：Co-Packaged Optics（CPO），共封装光学。将硅光子光引擎（PIC，Photonic Integrated Circuit）通过2.5D/3D先进封装技术与交换机ASIC芯片集成在同一封装基板上，光信号在封装内部完成光电转换后直接进入芯片，消除传统面板插拔式光模块的长距离电信号传输路径，从根本上降低功耗、提升带宽密度。

**传统方案 vs CPO方案：**

| 对比维度 | 传统可插拔光模块 | CPO共封装光学 |
|---------|----------------|-------------|
| 光引擎位置 | 交换机面板，通过QSFP/OSFP连接器插拔 | 交换机ASIC封装内部，紧邻芯片DIE |
| 电信号传输距离 | 面板到芯片约200-500mm PCB走线 | <10mm封装内互联 |
| 是否需要独立DSP | 每端口独立DSP芯片（功耗占50%+） | 可集成/简化DSP甚至完全取消 |
| 单端口功耗 | 800G端口约15-20W | 800G端口约8-12W（降低30-50%） |
| 带宽密度 | 受面板物理空间限制，单槽最大800G | 不受面板限制，单芯片可达51.2T甚至102.4T |
| 散热方式 | 风冷即可满足 | 需要液冷辅助（光引擎+ASIC集中发热，热密度翻倍） |
| 可维护性 | 支持热插拔，故障端口可在线更换 | 封装后不可现场更换，需整板返修，可靠性格外重要 |
| 商用进度 | 当前绝对主流（渗透率>95%） | 2026年规模商用起步，2028年渗透率预计>30% |

**核心优势：**
1. **功耗降低30-50%**：取消面板连接器+缩短PCB走线=大幅降低信号驱动功耗，DSP简化或取消是最核心的节能来源
2. **带宽密度翻5倍**：封装内微凸点互联密度远超面板连接器，单芯片可支持51.2Tbps交换容量，满足AI集群800G/1.6T互联需求
3. **信号完整性大幅提升**：超短距离封装内互联，减少信号反射、串扰、衰减，降低误码率
4. **硅光子技术成熟曲线加速**：硅基光引擎与CMOS工艺兼容，随着量产规模扩大成本快速下降

## 四、产业链位置

| 产业链环节 | 主要作用 | 代表公司/板块 | 小白理解 |
|-----------|---------|-------------|---------|
| 上游（硅光芯片+外置激光器） | 提供硅光子PIC晶圆和外置激光器光源(ELS)，每台CPO交换机需16-32个独立激光器 | Coherent、Lumentum、Intel、Ayar Labs | 发动机核心零部件厂——没有好零件装不出好发动机 |
| 中游（CPO光引擎制造+封装集成） | 将PIC光引擎+EIC电芯片+交换ASIC通过先进封装集成在一起 | 台积电(COUPE)、Broadcom、NVIDIA | 把发动机装进车身的组装厂——封装工艺决定良率和性能 |
| 下游（CPO交换机整机） | CPO交换机整机设计制造，交付云厂商部署 | Broadcom(Bailly)、NVIDIA(Spectrum-X)、Cisco | 整车厂——交付给最终用户 |
| 配套（液冷散热+高密度光纤连接） | CPO高密度封装需要液冷方案和专用高密度光纤连接器(如MPO-16/SN) | CoolerMaster、Senko、US Conec | 散热系统+专用油管——缺了这两样车跑不起来 |

> CPO位于AI算力 **L2 设备与零部件 → L3 核心产品 的网络层**——CPO交换机是AI数据中心内部GPU间数据传输的"高速公路枢纽"，直接决定GPU集群的互联带宽上限。一台CPO交换机出问题，几百张GPU卡着等数据。

> ⚠️ "沾边概念"类公司需注意：CPO本质上是"替代传统可插拔光模块"的技术路线。国内多数光模块公司的核心竞争力在于800G/1.6T可插拔光模块的快速研发和低成本制造，而CPO时代这一能力将被封装集成能力取代。真正受益的是具备硅光芯片设计能力的公司，而非传统光模块组装厂。把"我们能做光模块"等同于"我们能做CPO"是当前最大认知误区。

## 六、投资关注点

1. **Broadcom Bailly CPO交换机客户认证进度**：是否从"送样测试"阶段进入"批量采购"，首批订单的客户名称和规模是CPO商业化最关键的验证信号
2. **NVIDIA Spectrum-X CPO交换机2026Q3交付时间表**：是否如期交付，首批交付规模和客户部署反馈（良率、功耗、可靠性数据）
3. **台积电COUPE封装产能爬坡**：CPO封装是全新工艺（PIC+EIC+ASIC三维集成），良率和产能是否满足2026-2028年需求爆发
4. **CPO vs LPO（线性驱动可插拔）路线之争**：LPO取消DSP但保留可插拔形态，如果800G LPO性能和成本优于预期，可能延缓CPO渗透2-3年
5. **外置激光器(ELS)供应链安全**：每台51.2T CPO交换机需要32-64个独立激光器，Coherent/Lumentum产能扩张是否能跟上需求

## 七、风险提示

| 风险 | 如果发生，会怎样 |
|-----|----------------|
| CPO商业化进度不及预期 | Broadcom/NVIDIA CPO产品延迟交付→传统可插拔光模块生命周期延长→CPO相关公司估值大幅回调，LPO方案占据过渡期市场 |
| LPO方案意外成功压制CPO渗透 | 线性驱动可插拔光模块(LPO)以显著更低成本满足800G/1.6T需求→CPO渗透率从市场预期的30%骤降至<10%→CPO投资逻辑崩塌 |
| ELS激光器良率/可靠性问题爆发 | CPO交换机无法热插拔维修，ELS故障需整板返修→云厂商运维成本飙升→大规模退货或削减订单→信任危机蔓延整个CPO生态 |
| 封装良率瓶颈导致成本居高不下 | PIC+EIC+ASIC三维封装良率长期<70%→CPO单端口成本是传统方案的2-3倍→经济性不成立→云厂商放弃CPO路线 |
| 技术路线分裂生态碎片化 | Broadcom/NVIDIA/Intel各家CPO方案互不兼容（MSA多源协议未统一）→云厂商被单一供应商锁定→采购决策延迟→行业规模效应无法形成 |

## 八、如何判断是真逻辑还是炒概念

| 判断维度 | 应该看什么 | 小白容易误判的地方 |
|---------|-----------|------------------|
| CPO产品是否真实量产/商用 | Broadcom Bailly是否出现在云厂商正式招标文件中；NVIDIA是否公布CPO交换机具体交付客户和数量 | 把"研发路线图PPT"当"即将量产"，把"实验室Demo"当"商用产品" |
| 公司是否有硅光芯片设计能力 | 公司是否拥有硅光PIC设计团队+流片记录+硅光专利组合+硅光产品收入 | 把"做传统光模块的"自动等同于"能做CPO"，把"采购硅光器件"当"自研硅光" |
| 是否与先进封装厂有实质合作 | 是否已进入台积电COUPE等先进封装客户名单或已送样流片 | 把"和台积电有晶圆代工关系"当成"CPO封装合作"——两者是完全不同的合作层级 |
| 收入占比和订单可见度 | CPO/硅光相关产品在营收中的占比是否>5%且有季度增长趋势 | 把"布局中""储备技术""成立了研发小组"当成"已有收入" |
| 传统光模块业务是否面临替代风险 | 公司可插拔光模块业务占比越高，CPO替代的风险敞口越大 | 以为"既有传统光模块又有CPO"是双保险，实则是左右手互搏——旧业务被新业务替代 |

## 十、相关概念链接

- **【Agentic AI】** — Agent推理带来的Token指数增长→数据中心网络带宽需求同步爆发→CPO是物理层面满足带宽增长的唯一路径
- **【CoWoS先进封装】** — CPO将光引擎与交换芯片像CoWoS封装GPU+HBM一样集成在封装基板上，共享"异构集成+先进封装"底层逻辑；台积电COUPE平台直接基于CoWoS技术
- **【硅光技术】** — CPO的核心技术基础是硅光子集成电路(PIC)，硅光芯片的调制速率、插损、良率直接决定CPO的商业化进度和成本曲线
- **【HVDC高压直流供电】** — CPO降低光互连功耗30-50%，HVDC降低数据中心供电损耗，两者同属"AI基础设施能效革命"的核心技术组合
- **【DSP光芯片】** — 传统可插拔光模块中DSP功耗占比超50%，CPO架构的核心价值之一就是简化或取消独立DSP，DSP产业链面临重塑
