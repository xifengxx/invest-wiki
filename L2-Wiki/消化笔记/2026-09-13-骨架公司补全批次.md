## 执行规则

1. **L0 归档强制**：先写 `L0-原始资料池/03-新闻/2026-09-13-{公司}-{类型}.md`，再写 L2
2. **Write 重建**：骨架无实质 body 内容（已逐家验证），用 Write 重建不违反 L1「防数据丢失」规则的立意
3. **不推测原则**：无可靠来源的字段留空，不编造。私有公司（OpenAI/Anthropic）改用融资/估值口径
4. **分歧标注**：多来源数据冲突时标注区间与分歧，不强行取单值
5. **成本纪律**：串行处理（不派发大量并行子 Agent），每批 5 家后统一编译一次
6. **⚠️ YAML 中禁止 Markdown 加粗**：YAML 列表项若以 `**加粗**` 开头，`*` 会被解析器当作 **alias（别名）**，导致整个 frontmatter 解析失败、该实体变成 `unknown`。W5 曾因此产生 3 个 unknown 实体（zdt / empyrean / cohere）。
   - ❌ `- **North** Agent 平台`
   - ✅ `- North Agent 平台`
   - **Body 段内可以正常使用 `**`**，限制仅适用于 YAML frontmatter
   - 同理需避免：以 `*`、`&`、`!`、`%`、`@`、`` ` `` 开头的裸列表项
7. **编译前后必查**：`build_wiki_data.py` 输出中的 `unknown: N` 必须为 0，任何非 0 都说明有 frontmatter 解析失败

## W1-W2 横向观察

1. **AI 算力链条的利润正在从"芯片"向"封装/载板/互联"扩散**：长电（运算电子+40.4%）、通富（+347%）、深南（IC载板+110.76%）、Amphenol（IT datacom +89%）四家的高增长共享同一驱动源
2. **"非经常性损益"是本批的重复主题**：通富微电 9.70亿、Apple 关税退款、Amphenol 关税回收 $8,000万——**多家公司表观利润含一次性因素，需用扣非口径判断真实景气度**
3. **客户集中度是被普遍低估的风险**：通富微电 AMD 占 48.98%；长电运算电子占 30.1%
4. **估值与基本面背离的极端案例**：中科飞测 PS ~55倍却亏损 1.27亿
