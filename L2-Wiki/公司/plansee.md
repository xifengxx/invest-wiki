# Plansee

**这本质上是一家"钨"的公司。** 1921 年成立于奥地利，专精难熔金属（钨钼钽铌）。钨回收率 92%、钨前材料全球份额 12%（年约 14,000 吨），并通过持股 Almonty（钨矿）与 Molymet（钼，31%）锁定上游——**在关键矿产被地缘政治武器化的时代，这个位置的价值在上升**。

#### FY2025/26 详情

**这是一个"此消彼长"的年份**：汽车、半导体、能源技术三大市场需求疲软，但被**航空、国防、医疗技术**的增长抵消，最终实现+4%的温和增长。

**国防是意外增长点**：航空/国防/医疗的增长抵消了核心工业市场的疲软，**国防/军备约占营收8-10%**。在地缘政治紧张持续的背景下，这块业务的确定性在提升。

**研发投入€9,500万**（含研发总计约€2.5亿），相对€23.5亿营收的比例约4%（或含研发口径约10.6%），在材料行业属较高水平。

## 研发投入与专利

- 核心壁垒：
  1. **百年难熔金属工艺积累**（1921年成立），覆盖钨钼钽铌全品类
  2. **钨回收率92%的技术闭环**——在关键矿产供应紧张时形成成本与供应双重优势
  3. **上游股权绑定**（Almonty钨矿约10%、Molymet钼31%）
  4. **全球溅射靶材前五大厂商之一**（份额超40%的头部集团成员）
  5. 36个生产基地的全球布局支撑"Local for Local"
- **主要风险**：
  1. **下游周期性**——FY2025/26 汽车/半导体/能源三大市场同时疲软
  2. **地缘政治与出口限制**——公司明确提示贸易冲突与出口管制风险（钨是中国限制出口的关键矿产之一）
  3. **原材料价格波动**——钨钼价格直接影响成本
  4. **竞争对手规模更大**——Materion、JX Nippon、三井金属等均为大型集团
  5. **中国厂商追赶**——江丰电子等中国靶材企业份额持续提升
  6. **数据披露有限**——未上市，无公开市值；靶材业务细分数据未获取
