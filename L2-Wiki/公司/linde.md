# Linde plc

全球最大工业气体+电子特气供应商（半导体电子特气~23-25%份额），TTM营收$34.65B，市值$240B，每座AI芯片Fab都是10-15年长期气体合同，人类已知最稳定的半导体上游商业模式。

## 产品与客户结构

| 层级 | 内容 |
|------|------|
| 现场制气 | 为Fab建设ASU和管道供气，合同10-15年并含通胀调整 |
| 电子特气 | 超高纯氮、氩、氦、氢、硅烷、氟碳气体和前驱体 |
| 工业气体 | 氧气、氮气、二氧化碳服务化工、钢铁、医疗和食品 |
| 半导体客户 | 台积电、三星、Intel、SK海力士等先进Fab |
| 交付形式 | On-site、Merchant液体气和Packaged gases组合 |

半导体客户真正需要的是“不间断供应 + 纯度 + 灾备 + 长期价格可预测”。Linde在项目设计、气体纯化、管道投运和远程监控上的积累，使其比单纯卖瓶装气体的公司更难替代。

## AI Fab增长引擎

AI芯片带动先进逻辑、HBM和先进封装扩产，而每座新建Fab从洁净室投运前就需要高纯气体。Linde通过跟台积电亚利桑那、日本、德国，Intel Ohio和三星Texas等项目绑定，把一次Fab capex转化为长期收入。电子气收入弹性还来自工艺步骤增加：EUV、刻蚀、清洗、沉积和退火对气体种类与纯度要求都在提高。

## 竞争定位与风险

| 对手 | 差异 |
|------|------|
| Air Liquide | 全球#2，欧洲和亚洲项目强；Linde规模与北美项目更强 |
| Air Products | 清洁氢战略更激进，半导体气体组合相对更窄 |
| 大阳日酸 | 日本和亚洲电子气体市场强势 |

风险包括电价和天然气成本、大型项目执行延期、半导体Fab建设节奏变化，以及合同价格调整滞后。若AI驱动的新Fab集中推迟投运，Linde的新增收入会延后，但已有长期合同通常仍能提供缓冲。
