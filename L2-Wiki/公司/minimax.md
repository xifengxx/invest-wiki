# MiniMax

中国大模型公司里"效率路线"最激进的一家——成立至 2025 年 9 月累计研发花费约 US$5亿，约为 OpenAI 的 1%，却做出了 M2/H3 这样的开源旗舰。但 H1 2026 的故事是**商业模式反转**：开放平台及企业服务首次超过 AI 原生（63.4% vs 36.6%），同时毛利率环比大降约 16pp、经调整亏损扩大 111%。

> ⚠️ **成立时间多口径**：天眼查记境内主体 2021-11-03、同花顺记开曼上市主体 2021-06-30、**官网自述"early 2022"**、Reuters 亦记 2022 年初。

### C 端产品（AI 原生）
- **Talkie（海外）/ 星野（国内）**：AI 角色扮演/陪伴平台，订阅+虚拟货币+广告。合并月活约 **2,005–2,000万**，付费用户139万，25Q1–Q3 收入 **US$1,875万**（+39%，占公司35.1%）。用户日均使用超70分钟（全球大模型应用前五）。Talkie 用户分布：美国55%、菲律宾、英国、孟加拉。**ARPPU 约 US$5**
- **海螺AI（Hailuo AI）**：视觉/视频生成平台，分级订阅（US$9.99 基础 / US$199.99 至臻）。累计用户 **4,234.8万**、收入 **US$1,746.4万**（截至2025-09口径），付费用户31万，**ARPPU 约 US$56**（是陪伴产品的约11倍）。留存率不足1%曾被媒体点名为隐忧
- **MiniMax Code**（原 MiniMax Agent）：2025-06 推出通用智能体，2026-05 更名 Code，2026-08-07 发布 **Code 2.0**（基于开源 Pi agent 框架重建）
- **MiniMax Design**（商业内容 AI Agent 平台）、**MiniMax Audio**

### B 端（开放平台）
文本/语音/视频/图像/音乐全模态 API，按用量计费。付费客户 100（2023）→ 700（2024）→ **2,500**（25Q1–Q3）；**企业客户与开发者超200万**（H1 2026）。M2 API 定价约 $0.30/M 输入、$1.20/M 输出。

1. **语言模型主线**：abab 5 → abab 6 → abab 6.5 → MiniMax-01 → M1（开源 RL 推理）→ M2（MIT 开源）→ M2.1 → M2.5 → M2.7（"模型参与自我迭代"）→ **M3**（428B总参/23B激活，1M上下文，MSA 稀疏注意力）。下一步 **M3.1 / M3 Pro / H3.1**
2. **开源策略**：M1/M2/M2.7/**H3 均开源可下载权重**，H3 为首个开源多模态生成模型；H3 发布一个月内出现**超300个公开衍生模型、下载超2,400万次**。闫俊杰承诺个人5%股份中 **1% 用于支持开源社区**。开源被视为加速企业采用的关键杠杆
3. **效率路线**：**Forge RL 系统**（前缀树合并 rollout，40倍RL加速）；**M3.1 目标把推理成本降至 M3 上线时的约1/3**，以降价换 token 规模，从而改善毛利率
4. **多模态生成**：H3 统一文本/图像/视频/音频上下文，2K、15秒、原生立体声；视频定价 **0.8元/秒**（约同业旗舰1/3）
5. **算力自主**：M3 与 H3 推进国产芯片适配（昇腾/摩尔线程/沐曦/昆仑芯/海光/壁仞等），大规模国产算力集群将上线承担真实生产流量
6. **A+H 资本布局**：2026-05-29 启动科创板上市辅导（目标第五套标准）

### 主要风险
1. **版权诉讼（实质法律风险）**——2025-09-16 迪士尼、环球影业、华纳兄弟探索在加州中区联邦法院起诉 MiniMax 及 Nanonoble Pte Ltd（海螺AI），涉约 **500件注册作品**，法定赔偿上限合计最高 **US$7,500万**；**2026-05-23 法官驳回 MiniMax 的驳回动议**，案件继续审理。另有爱奇艺 2025-01 起诉（索赔10万元）。公司在招股书中否认直接侵权、主张"工具中立"与合理使用

5. **客户集中度**——来自米哈游的收入占比长期偏高（既是股东又是客户）
6. **出口管制与海外合规**——收入60–73%来自海外，面临数据/内容合规风险；**未被列入 BIS 实体清单**（对比智谱已列入），但受 2022-10 芯片限制、2025-01 对华对外投资最终规则（EO 14105）、2025-04《远程访问安全法案》潜在影响

8. **C端留存隐忧**——海螺AI 留存率不足1%曾被媒体点名；Talkie/星野受陪伴赛道监管与竞争双重影响
