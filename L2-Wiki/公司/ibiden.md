# Ibiden

AI 芯片真正的物理瓶颈之一不在晶圆厂，而在这家 1912 年成立的日本陶瓷公司手里——FC-BGA 载板需求超过供给。管理层把全年营业利润指引从 ¥900 亿直接上调到 ¥1,270 亿，是供应链紧张最直白的证据。

#### 最新一期详情

**超预期 + 大幅上调指引 = 供应链紧张的量化证据**。营业利润同比+52%、EPS超预期20.6%，管理层随即将全年营业利润指引从¥900亿上调至 **¥1,270亿（+41%）**。这不是需求预期改善，而是**已实现的供需失衡**——大尺寸、高层数FC-BGA供不应求。

## 产品线详解

### AI 服务器 FC-BGA（核心增长引擎）
**FC-BGA 载板是连接高性能AI芯片与主板的关键部件，已成为关键供应链瓶颈，需求超过供给**。公司作为 **FC-BGA 市场领导者**，在大尺寸、高层数载板领域具备技术优势与高市场份额（野村口径）。
**长期目标：AI 服务器载板收入到 FY2030 达 ¥4,750亿——约为 2024 年水平的 2.5 倍。**

### 通用 FC-BGA / CPU 载板
Intel、AMD 等 CPU 载板业务，是长期基本盘。当前产品结构从 GPU 向**交换IC与CPU**扩展，反映AI数据中心网络芯片需求的增长。

### 陶瓷与建材
公司1912年起家的传统业务，提供周期缓冲。

## 研发投入与专利

- 核心壁垒：
  1. **FC-BGA 全球龙头地位**，大尺寸、高层数载板的技术与良率优势
  2. **百年陶瓷工艺积累**迁移至载板制造（陶瓷烧结与载板的共烧工艺同源）
  3. 与 Intel、NVIDIA 的长期认证关系
  4. **产能稀缺性**——大尺寸高层数载板全球供给集中，扩产周期长
- **主要风险**：
  1. **客户集中度**——AI 芯片客户（NVIDIA/Intel）订单波动直接影响业绩
  2. **产能扩张的周期风险**——若AI资本开支见顶，新产能可能过剩（且扩产决策在FY3/27前就要做）
  3. **国产追赶**——深南电路已实现 FC-BGA 规模化量产，长期将侵蚀份额
  4. 与欣兴电子、AT&S、三星电机的竞争
  5. **ABF膜等关键材料供应集中度高**，存在材料端瓶颈
