# 华海清科

国产 CMP 设备的绝对龙头——国产销售占比超 90%、累计出机破 1,000 台，这是一个几乎没有国产竞争者的位置。更有价值的是平台化延伸：减薄设备卡位 3D IC/HBM，离子注入机收入一年增 722%。

## 财务状况

财年为自然年。营收高增，利润端受新品开拓与折旧压制，但Q2已现边际改善。

#### 1H26 详情

**"营收+35.58% 但归母仅+11.44%"的差距**来自：①**新产品市场开拓**（新机型定价与验证成本）；②**人工成本与折旧增加**（产能扩张与团队扩充）。毛利率-3.09pct 是直接体现。

**但Q2已经转向**：毛利率环比 **+1.25pct** 至43.56%、期间费用率同比 **-3.04pct**——说明新品开拓的初期成本正在被规模效应吸收。这是判断后续盈利弹性的关键信号。

## 产品线详解

### CMP 装备（基本盘）
已在**先进逻辑、先进存储、先进封装**批量落地；**国产CMP装备销售占比超90%**；截至2026年中期末**累计出机突破1,000台**。

新机型进展：
- **Universal-S300** 获客户批量订单
- **Universal-S300A** 首台交付头部存储客户验证
- **Universal-300FS** 切入国内头部**逻辑客户供应链**并获**大批量采购订单**
- **Universal-H300** 完成批量交付及验收
- **Master-P510APEX**：**国内首台 510×515mm 全自动板级CMP量产装备**，获先进封装核心客户订单

### 减薄装备（第二曲线，卡位 3D IC/HBM）
覆盖国内**多数头部晶圆制造及封测企业**，1H26 **新签订单再创新高**，在 **3D IC、HBM** 等高端应用形成**先发优势**。
- **减薄抛光一体机累计出货超20台**，获多家头部企业重复订单
- 新品首台出机：**Versatile-GH300**（12英寸先进存储，性能达行业领先）、**Versatile-GN200**（化合物晶圆）、**Versatile-GR200**（8英寸留环式）
- 划切及边缘抛光装备客户导入取得积极进展

> 减薄是 HBM 堆叠的核心工序，华海清科在此的卡位直接受益于AI存储需求。

### 离子注入装备（高增长）
已实现 **12英寸大束流离子注入机各型号全覆盖**，加速推出高能系列。
- **iPUMA-LE** 交付国内**先进存储龙头**
- 首台12英寸低温离子注入机 **iPUMA-LT** 推进客户端验证
- **离子注入机（芯嵛）收入 7,045万元，同比 +722%**

### 晶圆再生服务
获多家头部晶圆厂**批量长期订单**；**昆山扩产后总产能将提升至60万片/月**。属经常性收入，提升盈利稳定性。

## 研发投入与专利

- 核心壁垒：
  1. **国产CMP装备销售占比超90%**——几乎是唯一国产供应商
  2. **累计出机破1,000台的装机基数**——设备商的护城河来自存量装机带来的耗材与维保收入
  3. **减薄设备卡位 3D IC/HBM**——直接受益于AI存储需求
  4. **平台化战略**（CMP+减薄+离子注入+晶圆再生+湿法），降低单一产品依赖
- **主要风险**：
  1. **毛利率下滑3.09pct**（新品开拓+折旧），利润增速（+11.44%）远低于营收（+35.58%）
  2. 与 **Applied Materials、Ebara** 在CMP领域的技术代差
  3. **离子注入机规模仍小**（7,045万元），平台化尚需验证
  4. 股价波动极大（52周 82.33 - 374.85元），估值对业绩兑现高度敏感
  5. 下游扩产不及预期、产品验证周期拉长的风险（来源明确提示）
