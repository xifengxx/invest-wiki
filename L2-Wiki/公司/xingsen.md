# 兴森科技

**归母 +283.27% 是这六家里最容易误读的一个数字。** 同期合并口径净利润仍亏损 559.56万元——差额来自少数股东损益 -1.16亿元，即 FCBGA 项目的亏损由少数股东承担。看这家公司必须同时看两个口径。

## 财务状况

财年为自然年。**归母口径大幅改善，合并口径仍亏**，真实原因是 BT 载板（CSP）放量而非 FCBGA。

| 营业收入 | **40.38亿元** | **+17.86%** |
| 归母净利润 | **1.11亿元** | **+283.27%** |
| 扣非归母净利润 | 1.25亿元 | +166.90% |
| 综合毛利率 | 20.95% | **+2.5pct** |
| 经营活动现金流净额 | 284.09万元 | 由 -1.69亿元转正 |

### ⚠️ 口径背离（必须并列看）

| 项目 | 值 | 说明 |
|------|-----|------|
| 归母净利润 | **+1.11亿元** | 表观大幅改善 |
| **合并口径净利润** | **-559.56万元** | 同比收窄 8,141.67万元，**仍亏损** |
| **少数股东损益** | **-1.16亿元** | 主要因 FCBGA 项目亏损由少数股东承担 |

> **结论**：归母 +283.27% **并未反映全部经营亏损**。经营现金流仅 284.09万元（转正主因收到大额增值税留抵退税，非经营性改善）。用归母口径单独下"景气反转"结论是误读。

## 产品线详解

### 半导体业务（1H26 收入13.29亿元，+59.92%，毛利率1.79%，+18.57pct）

**IC封装基板（1H26 收入12.09亿元，+67.34%，毛利率-0.36%，+24.81pct）**
- 收入**主要由 CSP 封装基板（BT载板）贡献**——这是本期真实的增长来源
- 毛利率接近盈亏平衡（-0.36%），同比大幅改善 24.81pct
- 2012年进入 IC 封装基板领域 → 2018年满产 → 2019年盈利；**BT封装基板国内仅三家具备量产能力和稳定客户资源，兴森为其中之一**

**FCBGA 封装基板（ABF载板）——期权与拖累并存**

| 项目 | 值 |
|------|-----|
| 收入占比 | 仍较小，**尚未大批量生产**——载板毛利率为负、拖累净利润的主因 |
| 1H26 费用投入 | **3.29亿元**（人工、折旧、能源、材料） |
| 量产准备 | 技术能力/产能规模/产品良率三层面**已完成量产准备**，处产能爬坡阶段 |
| 技术能力 | 具备 **20层及以下** FCBGA 量产能力 |
| 良率 | 低层板 **>95%**、高层板 **>90%**（另有浙商证券口径为 85%+，存分歧） |
| 订单 | 样品订单数量同比大幅增长，高层数、大尺寸产品占比持续提升 |
| 工程进度 | FCBGA 项目已完成 **68.73%** |
| 产能布局 | 珠海 FC-BGA 200万颗/月（已建成试产）；广州 FC-BGA 规划 2000万颗/月 |
| ABF载板产能 | **2.61亿颗/年（A股第一）** |

**判断**：FCBGA 是"当期拖累 + 长期期权"。3.29亿元的半年费用投入与微乎其微的收入，是载板毛利率为负的直接原因；但 20层以下量产能力、90%+ 良率、68.73% 工程进度意味着**量产节点临近**——这也是 ~302 倍 PE 押注的东西。

### 传统PCB（1H26 收入25.03亿元，+2.23%，毛利率25.56%，-0.76pct）
样板、小批量板起家，延伸至高多层板、HDI、类载板（SLP）、半导体测试板，并提供"PCB设计—制造—SMT贴装"一站式服务。应用于通信、网络、工业控制、国防军工、消费电子。**增速仅2.23%、占比从71.45%降至61.98%**——不再是增长来源，但仍是利润与现金流的稳定基本盘（毛利率25.56%远高于载板的-0.36%）。

### 子公司扭亏
宜兴硅谷、珠海兴科等前期亏损主体实现**扭亏为盈**。

## 融资与现金流

- **经营活动现金流净额仅 284.09万元**（上年同期 -1.69亿元），转正主因是**收到大额增值税留抵退税**——非经营性改善
- **定增计划**：募资不超过 **39亿元**，用于高阶 mSAP 基板智能制造及产业化项目（一期）及 IC 封装基板项目（三期）扩产
- **资本开支强度极高**：FCBGA 广州项目规划 2000万颗/月、珠海 200万颗/月，叠加定增 39亿元扩产
- 少数股东损益 -1.16亿元——FCBGA 项目采用合资结构，**亏损由少数股东分担**，这也是归母口径能转正的关键机制
- 宜兴硅谷、珠海兴科扭亏为盈，减少前期亏损拖累

  1. **ABF载板年产能 2.61亿颗/年，居A股第一**

- **主要风险**：
  1. **FCBGA 仍是净拖累**——半年费用投入3.29亿元、收入占比极小、尚未大批量生产

  4. **估值极高**——PE(TTM) ~302倍、PB ~11.86倍
