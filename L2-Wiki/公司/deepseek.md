# DeepSeek

以极致训练效率打破了"算力即壁垒"的行业叙事，也用极致的人才密度换来了核心作者被持续挖角。2026 年它终于走向资本市场——这不是战略进攻，更像是人才与算力双重压力下的必然选择。

## 财务状况

DeepSeek 为**未上市公司**，财务数据未公开，采用「融资 + 估值」口径。**估值与融资金额在不同媒体间分歧极大**，已逐项标注。

### 首轮外部融资（态度重大转变）

| 项 | 内容 |
|----|------|
| 背景 | 梁文锋曾定"三不"规矩：**不接受外部融资、不稀释股权、不被商业化时间表绑架**；并称"我们面临的问题，从来不是钱" |
| 募资目标 | **最高 500 亿元人民币**（约$73.5亿） |
| 结构 | 增资 500 亿元 = **内部增资 200 亿 + 对外募资 300 亿** |
| **梁文锋个人出资** | 或高达 **200 亿元**，约占本轮 **40%** |
| 投资门槛 | 机构 **50 亿元起投**，对 LP 亦有身份要求 |
| 潜在投资方 | **国家大基金洽谈领投**；腾讯、阿里、宁德时代被提及 |
| 资金用途 | 提升算力、改善员工福利、加强人才激励 |
| **最新进展（2026-09 路透）** | 已完成约 **$74亿融资**，**腾讯、宁德时代**等成为外部投资者；已聘**中信证券**，为可能登陆**上海科创板**做准备 |

### 母公司：幻方量化

2025年**平均收益率 56.6%**，按 **700亿元管理规模**计对应约 **400亿元收益**；幻方与出资人按二八分账，可提走七八十亿元，为 DeepSeek 研发提供资金安全垫。这是 DeepSeek 长期敢于"不融资"的底气来源。

## 产品线详解

### DeepSeek-V4（核心模型）
**2026-04-24 预览版上线并同步开源**，距上代 V3 相隔 **484 天**。核心特性：
- **百万字超长上下文**
- Agent 能力、世界知识、推理性能达**国内与开源领域领先水平**
- 技术报告 **58 页**

### V4.1（迭代版本）
计划 2026年6月推出，并加快大模型迭代发布节奏，向行业主流看齐。

### R2（未发布）
市场期待的大迭代版本 **R2 始终未发布**——是 DeepSeek 当前最受关注的悬念。

### API 与商业化
V4 系列 API 于 **2026年8月大幅调整价格并引入峰谷定价机制**，商业化明显提速。

## 融资与现金流

- **首轮融资最高500亿元**，梁文锋个人出资约占40%——**创始人自掏腰包是极强的信心信号**
- 母公司**幻方量化**持续输血（2025年收益约400亿元），是长期研发的资金安全垫
- **2026-09 路透称已完成约$74亿融资**（未经官方确认）
- 资金用途明确指向**算力采购与人才激励**——直指当前两大瓶颈

## 研发投入与专利

- 核心壁垒：
  1. **极致训练效率**——以显著低于同行的算力投入达到接近前沿的能力，这是DeepSeek最独特的资产
  2. **开源生态影响力**——V系列开源推动了全球低成本模型的行业标准
  3. 幻方量化的资金后盾 + 梁文锋 100% 表决权带来的决策效率
- **主要风险（三重压力，也是转向融资的动因）**：
  1. **人才流失**：V4 技术报告近 **300 名署名者中，10 个带星号标注"已离职"**；**郭达雅、王炳宣、魏浩然、阮翀**等核心作者先后被大厂挖走。融资可提供公开估值为员工期权定价，是对抗挖角的手段
  2. **算力受限**：高端算力紧张；开始招募 AI 超算集群运维、数据中心交付/运维岗位，**推进国产算力（华为昇腾）适配**
  3. **外部竞争**：同行纷纷聚集资本弹药，不及时行动可能失去先发优势
  4. **R2 长期缺席**：市场期待的大迭代迟迟未至，技术领先性存疑
