# 大唐微电子技术有限公司

中国信科体系内的**安全芯片「国家队」**——身份是它的护城河：国家指定第二代身份证设计与加工企业、社保卡芯片主要供应商。但它也是**典型的「认证壁垒厚、价格弹性薄」生意**：2026 H1 收入 +26.82% 的同时净利润 −11.88%，净利率从 34.7% 掉到 24.1%，现金流由正转负。证卡市场已进入存量替换期，eSIM 又在侵蚀 SIM 卡基盘，公司当前处在「守基本盘 + 找新场景」的过渡窗口。

## 产品线详解

### 智能卡芯片（基本盘）
- **社保卡芯片**：我国社会保障卡芯片**主要供应商，2019 年市占超 40%**（当年全国发卡 12.78 亿张）；社保卡覆盖全国 **28 个省份**、累计出货超 **5 亿枚**；三代社保卡市场份额稳定。
- **身份证芯片**：**国家指定第二代居民身份证设计与加工企业**，身份证芯片累计出货量突破 **6 亿枚**。
- **金融 IC 卡芯片**：已在**百余家商业银行**入围或商用；为**中国工商银行**提供解决方案，部署超 **5,000 万张**银行卡；金融社保卡芯片累计供货超 **3 亿枚**。**2013 年**通过 EMVCo 国际安全认证及银联卡芯片产品安全认证。
- **SIM/UIM 卡芯片**：开发中国首枚 **GSM 手机专用 SIM 卡**、**CDMA 手机专用 UIM 卡**、电话 IC 卡、IP 电话账号 IC 卡芯片及模块；**2003 年**开发中国首枚 GSM 手机 SIM 卡芯片及模块产品；**2002 年下半年高端 SIM 卡市场份额超 70%**，曾为中国移动、中国联通供货。⚠️ 上述为历史高点数据，近年份额未披露。

### 安全控制芯片与安全模组
- 安全控制芯片/安全 MCU，面向**车联网安全、物联网安全、智能家居安全**。
- 智能交通模块、生物识别安全芯片（指纹等）、**移动支付 / NFC-SWP** 解决方案。

### 后道封测能力（垂直自建）
公司宣称具备「**芯片设计 → 减薄划片 → 封装 → 测试 → 预个人化**」全链条自主可控能力，产能：

| 环节 | 年产能 |
|------|--------|
| 量产芯片测试产线 | 6,000 万片 |
| 减薄划片 | 超 6,000 万片 |
| 身份证模块封装 | 超 7,000 万片 |
| 非接模块测试 | 6,000 万片 |
| 接触模块测试 | 超 3 亿片 |

⭐ 这种**「设计 + 后道自有」混合模式**在证卡类安全芯片中是差异化点——证卡需要预个人化（写入个人信息），自有后道既保交付也保安全可控。
