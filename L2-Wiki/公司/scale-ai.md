# Scale AI

Scale AI把稀缺的人类专业判断变成可复用的AI训练、评测与治理资产。它的价值不在于替代GPU，而在于决定模型学到什么、如何对齐、何时能被企业或政府安全使用。

## 财务状况

Scale AI为非上市公司，官网与公开报道均未披露完整审计报表。可用口径是：2025年6月Meta以约$14.3B获得约49%股权，交易对Scale估值约$29B；Scale官网在2026年继续列示$29B估值、1,000+员工、累计15B人类决策和累计$1B贡献者支付。该交易金额用于股东退出和业务增长，不能等同于Scale收入。

## 产品线详解

| 产品线 | 内容 | 商业价值 |
|--------|------|----------|
| **Scale Data Engine** | 多模态数据采集、清洗、标注、RLHF和专家数据 | 前沿模型训练与对齐的基础投入 |
| **Evaluation** | 自动基准、专家评估、红队测试和安全审计 | 决定模型能否发布、部署和满足监管要求 |
| **Scale GenAI Platform** | 企业RAG、Agent、微调、评估和治理 | 把模型能力接入企业知识库与业务流程 |
| **Donovan** | 政府/国防场景的决策支持与私有化AI | 合同周期长，合规与安全壁垒高 |
| **Applied AI** | 医疗、金融、保险、公共事业等行业系统 | 从数据服务升级为业务结果交付 |

Scale的竞争壁垒在于“数据质量+评估可信+合规交付”的组合。标注价格容易被竞争，但当任务涉及博士级专家判断、敏感数据、政府安全审查和企业级审计时，客户更难只按单价采购。

## 技术路线图

- **多模型世界适配**：为不同任务选择/组合模型，补齐路由、评估、监控与成本控制
- **专家数据工业化**：把法律、医疗、数学、代码、国防等领域专家纳入生产流程，提升复杂推理样本质量
- **评估产品化**：从一次性基准转向持续回归测试、红队、安全政策和生产监控
- **Agent与企业治理**：为多步Agent提供权限、审计、失败分析和可复现评测
- **政府级部署**：强化私有云、数据主权、供应链安全和可解释性

2026年公司强调“可靠AI”和多模型路线，说明战略正在从单纯卖标注转向帮客户选择、验证、部署和持续管理模型。这个方向与企业预算更接近，但也要求产品化能力更强。

## 融资与现金流

- 2024年Scale曾完成约$1B融资，TechCrunch报道估值$13.8B，投资方包括Amazon和Meta
- 2025年Meta追加/确认约$14.3B投资并获得约49%股权，估值升至约$29B；资金用于投资者/股东支付和增长
- Meta交易后创始人Alexandr Wang加入Meta参与AI研发，但保留Scale董事身份；Jason Droege曾任过渡CEO
- 2026年7月Scale任命前Google Cloud COO Francis deSouza为CEO，重点推动企业与政府AI增长
- 非上市身份意味着无需披露自由现金流；若企业/政府合同增加，可缓解前沿实验室客户收缩带来的收入集中度风险

## 研发投入与专利

- 研发重点覆盖数据引擎、RLHF、专家评估、红队、Agent治理、私有化部署和行业工作流
- 官网披露累计向贡献者支付$1B，说明其护城河建立在规模化管理专家和标注贡献者的能力上
- 15B人类决策的累计数据不是可直接公开的数据集，而是与客户合同绑定的生产经验、工具链和质量控制体系
- 与Surge AI、Mercor、Turing和Micro1相比，Scale更强调全栈平台、政府业务和Meta战略协同；但也因Meta所有权面临中立性质疑
- 后续技术验证点是多模型评估与Agent治理能否成为企业/政府的必购层，而不只是模型训练前的辅助服务
