# 芯源微

国内涂胶显影设备的独家玩家——这个环节长期被东京电子（TEL）垄断，芯源微是国产替代的主要突破口。1H26 营收+26.47% 且前道新机型进入验证大年，但扣非仍亏 4,513 万，市值 717.6 亿对应 2026 年 PE 约 417 倍。

## 财务状况

财年为自然年。增收减利，处于设备验证期的高投入阶段。

### 1H26 核心指标

| 指标 | 值 | 同比 |
|------|-----|------|
| 营收 | **8.97亿元** | **+26.47%** |
| 归母净利润 | **806.22万元** | **-49.37%** |
| **扣非净利润** | **-4,513.64万元** | 亏损收窄 8.87% |
| 研发费用 | 1.38亿元 | — |
| 销售费用 | 9,250.05万元 | **+77.39%** |
| 管理费用 | 1.58亿元 | +22.66% |

### 2026 Q2 单季
营收 **5.66亿元**（+30.53%），归母净利润约 **0.05亿元**（环比+29%）。

#### 1H26 详情

**利润下滑的两个原因**（公司口径）：①**员工人数增长**带来薪酬、差旅费等费用增加——**销售费用+77.39%**，增速远超营收+26.47%；②**政府补助减少**。

**"增收减利"的行业逻辑**：半导体设备商在**新品验证期**需大量投入研发与客户支持人员，而收入确认滞后于装机验证。**2026年预计是前道涂胶显影设备新机型的验证大年**——当前的利润承压是换取未来订单的必要成本。

**但需注意**：归母净利仅806.22万元而**扣非亏损4,513.64万元**，说明账面盈利依赖非经常性损益（政府补助等），主业仍在亏损。

## 产品线详解

### 前道涂胶显影机（核心，国产替代主战场）
持续获得国内头部**逻辑、存储、功率客户订单**；**offline、I-line、KrF** 等机台在多家客户端**量产跑片数据良好**。涂胶显影机是光刻工序的配套设备（涂胶→曝光→显影），长期由**东京电子（TEL）垄断**——芯源微是该环节国产替代的主要突破者。

### 后道涂胶显影机及单片式湿法设备
继续获得**封装龙头客户批量重复性订单**，是稳定的收入基本盘。

### 高精度键合设备（战略新方向）
**已开启全面量产**，包含**临时键合机、解键合机**。键合设备对应 **CoWoS/3D 先进封装** 需求，是公司从涂胶显影向先进封装设备延伸的关键布局。

### 前道化学清洗机与 Frame 清洗机
新品取得客户验证或放量，与涂胶显影形成工序协同。

### 订单结构
2026H1 新签订单保持快速增长，其中**前道约60%、后道约40%**——前道占比更高，说明国产替代正在向技术要求更高的前道推进。

## 研发投入与专利

- 核心壁垒：
  1. **国内涂胶显影设备细分龙头**——该环节长期由东京电子垄断，国产突破者稀缺
  2. **前道涂胶显影机的客户验证进展**（offline/I-line/KrF 量产跑片数据良好）
  3. **向高精度键合设备延伸**——对应 CoWoS/3D 先进封装需求
  4. 前道（60%）+后道（40%）的订单结构，覆盖晶圆制造与封装两大环节
- **主要风险**：
  1. **主业仍亏损**（扣非-4,513.64万元），账面盈利依赖政府补助
  2. **募投项目四年仅投24%、两度延期**——资金使用效率与执行力存疑
  3. **估值极高**（2026年PE约417倍），依赖未来业绩兑现
  4. **与东京电子的技术代差**——TEL 在涂胶显影领域市占率极高，芯源微集中在 offline/I-line/KrF 等相对成熟机台，前道高端（ArF浸没式）尚未突破
  5. 销售费用+77.39%，费用管控压力大
- 机构预测：长江证券 2026-2028 归母 **1.79亿 / 5.21亿 / 9.84亿元**（PE 417/143/76倍）
