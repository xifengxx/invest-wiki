# SUMCO Corporation

全球半导体硅片#2（~20%份额），与信越化学双寡头垄断~55%全球市场，AI驱动硅片出货量复苏+13% YoY，但短期折旧+原材料通胀拖累利润，LTA合同提供收入稳定性。

SUMCO的现金流压力不是来自订单断档，而是来自“长合同收入、重资产折旧、上游原材料成本”三者同时夹住利润。现有现金仍能覆盖近期运营，但新增产能的经济性必须依赖AI/HPC需求带来的高纯度大尺寸硅片涨价与良率爬坡，不能再用旧的终端需求曲线外推。

## 需求与产品结构

| 产品/需求 | 说明 |
|-----------|------|
| 300mm抛光片与外延片 | 面向先进逻辑和HBM/DRAM，是AI服务器需求的主要载体 |
| 200mm与再生片 | 面向成熟制程和测试监控，提供产能利用率缓冲，但价格弹性低于300mm高端片 |
| LTA合同 | 与台积电/Intel/三星锁定3-5年量价，收入可见性高； downside 是下行期重签或议价会滞后反映 |
| 非AI终端 | 手机/PC仍在消化库存，抬高了整体盈亏平衡点 |

## 增长路径与风险

SUMCO的增长路径集中在三件事：提高大尺寸外延片/退火片占比、把折旧摊薄到更高良率、以及把AI/HPC专用硅片的长期合同重新定价。风险端则更具体：中国本土厂商从成熟节点向上渗透，环球晶圆继续扩产，若2027年后AI服务器增量放缓，重资产产能会先转化为利润表压力。当前估值已经反映较多周期悲观预期，但修复必须看到高端300mm ASP回升，而不是只有出货量回升。
