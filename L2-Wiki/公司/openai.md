# OpenAI

以"最前沿模型 + 最大流量入口"占据AI应用层制高点，但尚未证明可持续盈利——其估值本质是对"AI 应用层最终垄断者"的定价，而非对当前现金流的定价。

## 财务状况

OpenAI 为未上市公司，**无公开财报**，以下为媒体报道与二手估算，不同来源分歧较大（已在 L0 归档中逐项标注）。

### 经营指标

- ChatGPT **周活 9亿+**，付费订阅 **5,000万+**，处理速率 >150亿 tokens/分钟
- 企业客户收入占比 **40%+**，预计2026年底与消费端持平
- OpenAI 亦加入多只 ARK Invest ETF

## 产品线详解

### ChatGPT（消费端核心）
最大流量入口，订阅制（Plus/Pro/Team）。但**流量份额正被 Google Gemini 侵蚀，从 86.7% 降至 64.5%**，是估值最核心的隐忧。

### API 与企业服务
按 token 计费，企业收入占比已超40%。GPT 系列（含 o 系列推理模型）为开发者默认选项之一，但面临 Anthropic Claude 在企业市场的强力竞争。

### 算力基础设施
Stargate 数据中心计划 + **$5,000亿 AI 工厂融资平台**（与 Apollo/BlackRock/Blackstone/Brookfield/GS/KKR 合作）。与 NVIDIA 的"供应承诺→担保→融资平台"结构形成算力金融化闭环，市场争议点在于**循环融资风险**。

### 多模态与硬件
视频生成 Sora、AI 终端设备（与 Apple 前设计团队合作传闻）。

## 融资与现金流

- **2026-03-31 完成 $1,220亿融资**，投后估值 $8,520亿，**史上最大私募融资轮**
- $47亿循环信贷额度（JPM/GS/Citi/MS/WF），截至报道**未提取**
- **微软重组核心条款**：微软持股约 **27%**（价值约$1,350亿，历史投入约$130亿）；**收入分成封顶 $380亿（至2030年）**，较此前无上限条款减少约 $700-970亿；微软保留转售权至2032年
- 排他性放松：OpenAI 可使用多云多芯片（AWS/Oracle/Google Cloud、AMD/Trainium/Cerebras/博通Titan），但**微软仍是 OpenAI API 的独家云**
- **关键压力点**：软银 $400亿过桥贷款于 **2027年3月到期**，构成上市时点的硬约束

## 研发投入与专利

- 研发支出未单独披露，但从现金消耗（2026 ~$270亿）可推断绝大部分投向训练算力与人才
- 核心壁垒：**前沿模型能力 + ChatGPT 品牌与流量 + 与微软/英伟达/软银的资本-算力绑定**
- 主要短板：
  1. **无自研芯片能力**（依赖 NVIDIA，博通定制芯片尚在早期）
  2. **流量份额被 Gemini 侵蚀**
  3. **单位经济性未验证**——推理成本随用户增长线性上升，尚未证明规模效应
- 法律风险：Musk 诉讼、NYT 版权案
