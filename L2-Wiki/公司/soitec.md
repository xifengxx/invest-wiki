# Soitec

Soitec不是普通硅片厂：Smart Cut技术让它在SOI衬底上拥有近乎平台级的话语权。手机射频让公司完成了规模化，AI边缘、汽车功率和硅光则是它穿越下一轮周期的关键赌注。

## 财务状况

Soitec财年截至3月31日。FY2026（2025年4月至2026年3月）营收€592M、净亏€220M，较FY2025€891M、净利€92M大幅下滑，核心原因是智能手机射频去库存、汽车/工业功率需求疲软以及产能扩张后的固定成本放大经营杠杆。Yahoo口径最新毛利率16.3%、营业利润率-10.7%、净利率-37.1%。

## 产品线详解

| 衬底平台 | 技术特征 | 主要应用 |
|----------|----------|----------|
| **RF-SOI** | 高电阻率衬底、低寄生、线性度好 | 智能手机射频开关、天线调谐和LNA集成 |
| **POI** | 压电层与衬底结合 | 射频滤波器，覆盖4G/5G频段 |
| **FD-SOI** | 薄埋氧+超薄顶层硅，背偏置可调 | 低功耗边缘AI、车载雷达/处理器、混合信号SoC |
| **Power-SOI** | 埋氧隔离提升功率密度 | 汽车、工业电源管理和驱动芯片 |
| **SiC / Auto SiC** | 化合物衬底和Smart Cut转移 | 电动车逆变器、车载充电、工业电源 |
| **Photonics-SOI** | 光波导与硅光器件集成 | 数据中心互连、光模块、传感 |
| **Imager/MEMS-SOI** | 背照式传感、高深宽比MEMS结构 | 3D成像、指纹传感、惯性/压力传感器 |

Soitec的价值不在硅片面积，而在“材料结构+器件工艺”绑定。RF-SOI进入手机射频平台后，衬底规格会与芯片设计和代工工艺共同锁定；FD-SOI和SiC则需要更长的平台认证。这带来高毛利潜力，也放大了下游单一应用去库存时的收入波动。

## 技术路线图

- **Smart Cut扩展**：从SOI向SiC、压电、光子学和异质堆叠材料扩展，把薄层转移能力平台化
- **300mm升级**：RF-SOI和FD-SOI继续向300mm迁移，提高单片产出和晶圆均匀性
- **RF-SOI 5G/6G**：支持更高频段、更高线性度和更高集成度的射频前端
- **FD-SOI边缘AI**：以背偏置调功耗，面向可穿戴、工业边缘、车规处理器和低功耗推理
- **SiC与功率电子**：Bernin 4等新产能支持SiC衬底和汽车功率器件需求，但短期需消化行业去库存
- **Photonics-SOI**：承接AI数据中心光互连、CPO和光学传感需求，是中长期第二增长曲线

## 融资与现金流

- FY2026净亏€220M，收入下滑叠加产能扩张使固定成本难以摊薄，是本轮财务压力的核心
- Yahoo接口未返回完整现金流明细；重点跟踪存货、资本开支、Bernin 4爬坡节奏和银行授信
- 公司股东结构包含BPI France、NSIG、CEA、员工持股和机构投资者，重大产能扩张通常依赖战略股东与资本市场协同

## 研发投入与专利

- 员工约1,961人，研发、工艺工程和客户支持围绕Smart Cut、晶圆键合、薄层转移、抛光、量测和新材料展开
- Smart Cut由CEA-Leti与公司共同产业化，已形成从基础专利、工艺授权到量产know-how的护城河
- 核心壁垒在于材料缺陷控制、埋氧层厚度均匀性、晶圆翘曲和与下游器件工艺的可制造性；SiC、光子学和堆叠材料都依赖这套能力外溢
