# Waymo

全球唯一在多个城市规模化商业运营的 Robotaxi——周付费订单 50 万、一年增长 10 倍，是真实的运营数据。但 280 倍的收入倍数意味着市场在为"自动驾驶最终赢家"的期权定价，而非为当下的现金流定价。

## 财务状况

Waymo 为 **Alphabet 控股的未上市公司**，无公开财报，采用「融资 + 估值 + 运营指标」口径。

### 融资与估值

| 项 | 内容 |
|----|------|
| 融资时间 | **2026-02-02** |
| 融资额 | **$160亿**（自动驾驶公司史上最大私募之一） |
| **投后估值** | **$1,260亿**（多数来源；eWEEK 另称近$1,100亿） |
| 估值增长 | 较 **2024年10月的 $450亿** 增长约 **2.8倍** |
| 领投方 | **Dragoneer、DST Global、Sequoia Capital** |
| 参投方 | a16z、Mubadala Capital、T. Rowe Price、Silver Lake、Tiger Global、Bessemer、Fidelity |
| **Alphabet** | **仍为多数股东**，本轮出资约 **$130亿**（最大份额） |
| 债务融资 | 另筹 **>$30亿无评级债券**（PIMCO/Blackstone/Sixth Street）——**首次转向债务市场** |

#### 财务特征

**典型的前沿基础设施型亏损结构**：Alphabet 承担了绝大部分资本投入（本轮$130亿），Waymo 需要证明的是**单城市运营盈利**。有分析认为，在资本耗尽前（约 **3-4 年**）必须验证城市级单位经济性。

## 产品线详解

### Robotaxi 出行服务（核心）
**周付费订单**：~40万（2026.2）→ 45万+ → **50万+（2026.3）**，较 **2024年5月的5万增长10倍**。
- 2025 全年约 **1,500万次**付费订单（约为上年的 **3倍**）
- 累计订单 **2,000万+ 次**
- 全自动驾驶里程 **1.00-1.27亿英里**
- 车队规模 **4,000+ 辆**
- **2026 目标：周付费订单 100万次**（联合CEO 称其为"拐点"）

### Waymo Driver（技术底座）
已迭代至**第六代**。安全记录：严重伤害事故较人类驾驶**减少约90%**（另有来源称92%）——这是其获取监管许可与公众信任的核心资产。

### 无人配送
与 DoorDash 在 Phoenix 合作无人食品配送。

### 平台分发
通过 Uber（Austin/Atlanta）、Lyft（Nashville）触达更大用户池，降低自建流量成本。

## 融资与现金流

- **2026-02 单轮融资 $160亿**，投后估值 $1,260亿
- **Alphabet 出资约 $130亿**，保持多数股东地位——**Waymo 的估值在实质上是 Alphabet 资产负债表的功能**
- **首次发行 >$30亿无评级债券**（PIMCO/Blackstone/Sixth Street），标志着从纯股权融资转向债务市场
- 未盈利，现金消耗依赖持续外部融资

## 研发投入与专利

- 研发投入未单独披露（并入 Alphabet Other Bets）
- 核心壁垒：
  1. **唯一在多个城市规模化商业运营的 Robotaxi**——运营里程与订单数据构成难以复制的先发优势
  2. **安全记录**（严重伤害事故减少约90%），是监管与公众信任的基础
  3. **Alphabet 的资金与 AI 技术底座**（TPU/模型能力）
- 主要风险：
  1. **单位经济性未验证**——尚无任何自动驾驶公司实现零人工介入运营，远程协助成本仍是未知数
  2. **估值极端**（收入倍数 ~280x），且高度依赖 Alphabet 背书
  3. **竞争**：Tesla 的纯视觉路线若跑通，成本结构优势可能颠覆 Waymo 的激光雷达路线
  4. **监管与审查**——远程协助规模、事故责任认定仍是监管焦点
  5. 资本消耗速度快，3-4年内需证明单城盈利
