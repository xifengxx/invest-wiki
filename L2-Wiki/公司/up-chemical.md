# UP Chemical

全球 HBM 前驱体三强之一——这是一个全球仅三家供应商、合计份额超 80% 的极窄赛道。它自 2004 年就开始给 SK 海力士供货，参与了每一代 DRAM 和 HBM 的材料迭代，是雅克科技这家中国材料公司拿到 HBM 入场券的关键资产。

#### 财务特征

**净利率约20.6%，是雅克科技体系内盈利能力最强的资产之一**。对比母公司雅克1H26整体归母净利率约12.4%，UP Chemical 的盈利质量明显更高——这反映了 **HBM前驱体的稀缺性溢价**（全球三家、份额超80%的寡头格局）。

## 产品线详解

### 高端 HBM 用前驱体（核心资产）
**全球仅三家可稳定量产的企业之一**（另两家：**德国默克**、**日本信越化学**），三家合计占该赛道 **超80%份额**。

HBM 前驱体用于 HBM 堆叠中的薄膜沉积环节，随着 HBM3E → HBM4 迭代，堆叠层数与工艺复杂度提升，**单颗HBM的前驱体用量与价值量同步增长**。

> 注：有供应链梳理称 UP Chemical 是 **SK海力士 HBM4 前驱体独家供应商、订单锁定至2027年**，并同时供货三星全部HBM产线。**此说法来自二手梳理，置信度较低**，仅供参考。

### DRAM / 3D NAND 前驱体
自2004年起供应 SK 海力士，参与**多代 DRAM 和 HBM 材料迭代**；同时长期供应国内存储龙头 **长鑫存储**。3D NAND 堆叠层数增加也带动前驱体用量提升。

- 作为雅克科技全资子公司，**无独立融资渠道**，资本开支由母公司统筹
- **产能扩张密集**：第三工厂（2026年底投产）+ 第四工厂（规划中）+ 母公司宜兴二期改建
- 母公司雅克科技1H26整体经营情况：营收45.13亿元（+5.12%）、**扣非净利仅+0.68%**——UP Chemical 的高增长是母公司业绩的主要支撑点
- 母公司股价波动剧烈：2026年7月1日市值1,124亿元 → 8月26日643.60亿元（两个月-43%），**估值对HBM叙事高度敏感**

## 研发投入与专利

- 核心壁垒：
  1. **全球仅三家可稳定量产高端HBM前驱体**的企业之一，三家合计占赛道超80%——半导体材料中集中度最高的环节之一
  2. **自2004年供货SK海力士**，参与多代DRAM/HBM材料迭代，**客户切换成本极高**（材料验证周期长、影响良率）
  3. 韩国本土产能，贴近SK海力士/三星的生产基地
- **主要风险**：
  1. **数据不透明**——无独立财报，投资者只能通过母公司分部数据间接跟踪
  2. **客户集中度极高**——高度依赖SK海力士与三星的HBM产能节奏
  3. **HBM4独家供应说法未经证实**（二手来源）
  4. **地缘风险**——中资控股的韩国企业，在中美韩技术管制背景下存在政策不确定性
  5. 与默克、信越化学的竞争，以及存储厂对材料供应商的持续压价
