# 沪硅产业

国产大硅片的"国家队长"。300mm 销量同比+90% 说明国产替代需求真实且旺盛，但毛利率 -8.34%、半年亏 9.65 亿——这家公司正在用亏损换取产能与份额，赌的是行业价格周期反转。

## 财务状况

财年为自然年。营收高增但**亏损同步扩大**，处典型的重资产爬坡期。

### 1H26 核心指标

| 指标 | 值 | 同比 |
|------|-----|------|
| 营收 | **23.17亿元** | **+36.51%** |
| 归母净利润 | **-9.65亿元** | **亏损扩大163.32%**（上年 -3.67亿） |
| 扣非归母净利润 | -9.58亿元 | -99.08% |
| 基本EPS | -0.292元 | 上年 -0.133元 |
| **毛利率** | **-8.34%** | **+4.76pct（改善）** |
| 净利率 | -44.43% | — |

### 2026 Q2 单季
营收 **12.33亿元**（+37.68%，环比+13.79%）；归母净利润 **-4.82亿元**。

### 其他关键指标

| 指标 | 值 |
|------|-----|
| 研发费用 | 2.59亿元（**占营收11.17%**，+2.01pct） |
| **经营现金流净额** | **1.79亿元**（上年 -4.62亿，**由负转正**） |

#### 1H26 详情

**亏损扩大的三条原因**（公司口径）：
1. 坚持 300mm 硅片及 300mm SOI 硅片的研发投入，**研发投入增加约1亿元**
2. 受汇率波动影响，**财务费用同比增加约2亿元**
3. **单价同比下降**，叠加以前年度高成本库存待消化，**资产减值损失增加约1.2亿元**

**积极信号有三**：①毛利率同比改善 4.76pct（-13.10% → -8.34%）；②**经营现金流由负转正**（+1.79亿 vs 上年-4.62亿）；③300mm 销量+90% 显示需求端强劲。

## 产品线详解

### 300mm 半导体硅片（核心增长）
1H26 **销量同比+90%以上**，收入同比 **+57%**（研报称因价格处阶段性低位，收入增幅低于销量增幅）。这是国产大硅片替代最直接的证据——国内晶圆厂正在大规模导入国产 300mm 硅片。

### 200mm 及以下硅片（成熟业务）
销量同比增加约16%，收入增长不足5%——同样是"量增价跌"。

### SOI 硅片
合计产能超 **6.5万片/月**，含 300mm SOI（用于射频、功率器件）。

### 受托加工服务
收入同比 **-22%**，是唯一明显萎缩的业务。

### 产能布局

| 产品 | 产能 |
|------|------|
| **300mm**（上海+太原） | **100万片/月** → 预计2026年底达 **120万片/月** |
| 200mm及以下抛光片/外延片 | >50万片/月 |
| SOI 硅片 | >6.5万片/月 |

## 融资与现金流

- **经营现金流净额 1.79亿元，由负转正**（上年 -4.62亿）——是本次财报最有价值的改善信号
- **上海新昇增资**：股东**国盛集团以现金+债转股形式出资 40亿元**，专项用于集成电路用 300mm 硅片产能升级项目；研报提及合计出资 **114.48亿元**
- 研发费用 2.59亿元（占营收11.17%）
- 财务费用同比增加约2亿元（汇率波动），是亏损扩大的重要因素
- **持续亏损意味着仍需外部融资支撑产能扩张**——国资背景（国盛集团）是关键保障

## 研发投入与专利

- 1H26 研发费用 **2.59亿元，占营收 11.17%（+2.01pct）**——持续加码
- 核心壁垒：**中国大陆规模最大的半导体硅片企业**；300mm 产能已达100万片/月（国内领先）；国资背景保障长期投入
- 全球竞争格局：硅片行业高度集中，**信越化学、SUMCO、环球晶圆、Siltronic、SK Siltron 五大厂商占据全球绝大部分份额**，沪硅产业在全球份额仍小
- **主要风险**：
  1. **毛利率为负（-8.34%）**，价格周期未见明确反转
  2. 持续亏损（机构预计 2026-2028 仍亏 -7.91/-4.10/-2.47亿，**逐年收窄**）
  3. 高成本库存消化尚未完成
  4. 重资产模式下折旧压力持续
- 机构观点：中银证券维持"增持"，认为**硅片景气度触底，看好2026年下半年价格改善**
