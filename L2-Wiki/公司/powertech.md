## 产品线详解

**服务别（2Q26）**：封装 **66%** / 测试 **23%** / SiP 与模组 **11%**
**产品别（2Q26）**：逻辑 **41%** / NAND **29%** / DRAM **19%** / SiP **11%**

测试占 23% 是这家公司与纯封装厂的关键差别——测试毛利高于封装，是毛利率能拉到 21.8% 的结构性原因。

| 技术 | 参数 / 现况 | 应用 |
|------|------|------|
| **FCBGA MCM** | 已量产至 **78×75mm**；**2026 Q3 导入 1× reticle 大芯片量产** | 大芯片 = AI / HPC |
| **TSV** | **via-middle + via-last** 双路线，**双面微凸块 (double-side micro bump)**，**TCB (Thermal Compression Bonding)** 堆叠 | 存储与逻辑堆叠 |
| **封装翘曲控制** | **≤10µm** | — |
| **CIS TSV CSP** | RDL 达 **5µm/5µm**（线宽/线距） | 图像传感器 |
| **TSV DDR5** | **2026 Q4 量产** | DRAM 堆叠 |
| **硅中介层 2.5D/3D** | 2023/12 与**华邦电**签署合作 | 2.5D/3D 集成 |
| **存储封装** | DRAM 堆叠 / NAND Flash / SSD / eMMC / UFS | 存储全品类 |
| **多芯片封装** | MCP / S-MCP | 移动与消费 |

## FOPLP 面板级封装（PiFO）

自有品牌 **PiFO®**，四种结构：Bump-free / Chip First / Chip Last / Chip Middle。

| 项目 | 力成 PiFO | 同业对照 |
|---|---|---|
| 面板尺寸 | **515×510mm** | 台积电 310×310mm、日月光 600×600mm、群创 700×700mm |
| RDL 能力 | 芯片背面 **≥5/5µm**、正面 **≥2/2µm** | — |
| 单片颗数 | 约 **45 颗大芯片** | 12 吋约 8–9 颗 |
| 光罩数演进 | 5× → 2026 年底 9× → 长期 14× | — |
| 月产能规划 | **6,000 片面板**（2026 建 3,000 → 2027 再 3,000 → 2028 全数） | — |
| 良率 | 90–95%（媒体口径，公司无统一数字） | — |
| 时程 | 官方口径「期望如期于 **2027** 顺利交付量产」 | — |
| 客户 | **AMD**（Venice CPU 平台，2027 年中量产）与 **Broadcom**（媒体口径） | — |

515×510mm 是「不大不小」的选择——比台积电的 310×310 大（有经济性），比日月光 600×600 与群创 700×700 小（良率与翘曲可控），是工程折中而非规模竞赛。相比之下，**2026 Q3 导入 1× reticle 大芯片量产是比面板尺寸更硬的指标**。

- 注意：6,000 片/月的规划在媒体间有 1,000 / 6,000 / 7,000 三种说法，公司未确认

## 与博通的新加坡合资

- **2026-07-16 董事会通过**：投资 **US$4 亿（约 NT$129 亿）**与 **Broadcom** 在新加坡设立**合资公司**，做**面板级先进封装基板**（加成式细线宽 RDL）
- **博通持股 >50% 主导营运，力成约 30%**；**2026 年底动工、2028 量产**
- 来源：`L0-原始资料池/03-新闻/2026-10-10-力成科技-调研.md`（input_20261010_003）

这是把 FOPLP 技术变现为「与客户共担资本开支」的结构——力成出技术与 30% 资金，博通出 >50% 资金并主导。对力成而言资本压力小于自建，代价是主导权与多数利润归客户。**注意与「力成自有 FOPLP 产能」是两件事，不要混为一谈。**
