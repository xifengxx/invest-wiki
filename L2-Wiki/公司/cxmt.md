# 长鑫科技

长鑫科技是国产DRAM体系从追赶走向规模竞争的关键载体，投资价值同时来自国产替代、AI推理内存需求和全球DRAM涨价周期。

## 财务状况

长鑫科技于2026-07-27在上交所科创板上市，发行价`¥8.66/股`，发行融资约`¥579亿`，上市首日涨幅被媒体统计在465%至471%之间，亚洲2026年IPO融资规模居于前列。

| 口径 | 指标 | 说明 |
|------|------|------|
| 2026Q1 | 营收`¥508亿` | 媒体披露口径，同比增长约719% |
| 2026Q1 | 归母净利`¥247.6亿` | DRAM价格上涨叠加国产替代放量 |
| 2026H1 | 营收`¥1,503亿` | 同比增长约874% |
| 2026H1 | 归母净利`¥776亿` | H1隐含Q2净利约`¥528亿` |
| 2026-09-15 | 总市值约`¥3.68万亿` | 收盘`¥54.22`，约`~$518B` |

需要强调，Q2分季值由H1减去Q1推算，后续应以半年报和审计口径复核。公司利润率受益于DRAM供需反转，但新厂折旧、HBM研发和地缘政策仍是长期变量。

## 产品线详解

| 产品线 | 客户与场景 | 竞争位置 |
|--------|------------|----------|
| **LPDDR5X/LPDDR6** | 国产旗舰手机、AI终端和汽车座舱 | LPDDR6完成研发验证，媒体报道速率达12.8Gbps |
| **DDR4/DDR5模组** | PC、服务器和国产算力平台 | DDR5放量是服务器收入主力 |
| **利基型DRAM** | 工业、网络、消费电子 | 与南亚科等利基厂商竞争 |
| **HBM3/HBM3E** | 国产AI加速器和推理集群 | HBM3试产，HBM3E良率仍处爬坡阶段 |

DRAM收入弹性来自三重因素：AI推理带动DRAM容量需求、传统服务器和手机补库存、以及海外供应链不确定下国产客户增加长单。HBM短期还不是收入主力，但对估值和技术卡位有决定性影响。

## 技术路线图

1. **LPDDR6规模化**：完成研发验证后推进手机与AI终端认证，玄戒O3等国产SoC是关键落地窗口。
2. **HBM3到HBM3E**：HBM3试产之后重点解决TSV、堆叠键合、测试良率和客户平台适配；公开报道显示HBM3E良率约25%，量产时点需谨慎。
3. **先进DRAM制程**：继续推进10nm级DRAM节点，平衡光刻设备获取、良率、成本和专利风险。
4. **产能扩张**：北京第二座DRAM基地计划推进，公司2030年目标建成第六座mega-fab。
5. **全球份额**：Counterpoint数据显示2026Q2市占率约10%、全球第四；媒体提及2030年30%目标，属于公司路线图而非已实现结果。

## 供应链与生态

DRAM IDM的上游约束比芯片设计更强。设备侧涉及刻蚀、沉积、清洗、量测和光刻；材料侧涉及硅晶圆、光刻胶、电子特气、CMP材料和高纯化学品。HBM叠加上游TSV、键合设备和先进封装测试环节。

本仓库NAURA、华海清科、拓荆科技等供应链词条中已出现指向长鑫体系的反向关系，可作为国产设备与材料合作的线索。但具体收入占比、采购单价和长协条款应以招股书、公司公告和客户披露为准。

## 风险与监管

- **地缘政治**：美国国防部曾将其列入相关清单，公司选择诉讼争取移除；设备维护、零部件和技术出口仍是核心风险。
- **HBM良率**：HBM3E若不能快速提升良率，会影响国产AI内存替代节奏，也会摊薄研发投入。
- **DRAM周期**：当前价格上行放大利润，但一旦供给集中释放或需求后移，收入和毛利率可能快速回落。
- **资本开支**：第六座mega-fab与多节点研发需要持续高投入，现金流和折旧压力要跟踪。
- **上市主体治理**：品牌名“长鑫存储”与上市主体“长鑫科技”需区分，避免关联业务口径误用。
