# Tokyo Ohka Kogyo (TOK)

全球光刻胶#2 + ArF浸没式全球#1，AI芯片先进制程驱动Q1 +23.6% YoY，FY2026E营收¥2,610亿，与JSR双寡头垄断全球光刻胶市场，YTD股价+67%。

TOK的报表特点是轻负债、高研发投入、客户认证周期长。无有息负债使它可以在不稀释股东的前提下扩大配方开发和产能，但光刻胶是“小批量、高纯度、强客户绑定”的生意，产能扩张必须跟随具体工艺节点认证，不能像硅片那样只看产能利用率。

## 产品结构与竞争位置

| 业务层 | 说明 |
|--------|------|
| ArF浸没式 | 全球#1，是主流先进逻辑/存储制造中的收入基本盘 |
| EUV光刻胶 | 与JSR竞争，在高NA EUV到来前持续扩客户数据包 |
| 高纯化学品 | 显影液、冲洗液与光刻胶配套供应，提高客户流程粘性 |
| 显示材料 | 提供周期平衡，但利润率和战略优先级低于半导体材料 |

TOK相对JSR的优势不是单一份额数字，而是“光刻胶+化学品”的组合：客户若把TOK纳入完整光刻工艺包，切换成本会超过单品类替代。风险则在于JSR/JIC若被大型化工集团整合，可能用更长资金期限和产能投入压缩High-NA窗口期的技术差距。

## 增长驱动与风险

FY2026上半年的强劲增长来自AI/HPC先进制程对ArF浸没式和EUV光刻胶的拉动，而不是手机市场全面复苏。展望下半年，高端逻辑晶圆排产和HBM/DRAM技术迁移是核心变量；若存储客户把光刻胶采购节奏推迟，收入弹性会先于利润率下降。其他风险包括原材料纯度成本、汇率波动和潜在化学废品处理成本上升，但零有息负债给了公司较厚的抗周期缓冲。
