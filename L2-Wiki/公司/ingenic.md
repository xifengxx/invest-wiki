# 北京君正

一家被贴上"RISC-V 概念"标签、但真实业绩由**存储涨价周期**驱动的车规芯片公司——2026H1 归母净利 +489.59% 的背后，是存储芯片毛利率 +14.59pct 与计算芯片毛利率 +28.69pct 的涨价传导。

## 产品线详解

### 存储芯片（占66.5%，本轮核心驱动）
1H26 收入 26.32 亿元（**+90.08%**），毛利率 **48.07%（+14.59pct）**。产品含 SRAM、DRAM、NOR Flash、2D NAND、eMMC，经北京矽成（ISSI）体系面向**汽车、工业、医疗**等高品质高可靠性领域——这类长协客户自 2026Q1 进入调价周期。

**四个增长来源**：① **DRAM** 供应持续紧张、售价涨幅较大（2026Q1 国内客户调价、Q2 国内继续 + 海外陆续，Q3 预计继续上调）；② **云端 AI 存储挤压产能**，利基 DRAM 供给被动收缩；③ **Flash 受益 AI 服务器与光模块**，512Mb/1Gb 大容量 NOR Flash 与 eMMC 持续增长，512Mb SPI NOR Flash 逐渐放量；④ 加大 **2D NAND** 研发与资源布局。

**产能保障**：公司提前备货，含 **20nm、18nm、16nm DDR4/LPDDR4**，预计可保证今明两年稳定供货——在存储缺货周期中，这是被低估的竞争壁垒。

### 计算芯片（占26.4%，毛利率最高）
1H26 收入 10.43 亿元（+72.66%），毛利率 **61.06%（+28.69pct）**——**毛利率提升幅度最大**。产品为智能视频 SoC、嵌入式 MPU、AI MCU，应用于智能视频监控、AIoT、工业与消费电子、生物识别及教育电子。

本轮增长部分来自**成本推动型提价**：受原材料 **KGD（已知良好裸片）缺货、涨价**影响，公司上调产品价格，销售收入同比强劲增长。需注意这与"量增"驱动的增长质量不同。

### 模拟芯片（占6.8%，增速最慢）
1H26 收入 2.70 亿元（+10.59%），毛利率 49.86%。产品含 LED 驱动、DC/DC、LIN/CAN/GreenPHY 等，与存储、计算产品形成车载与工业场景的配套销售。

### RISC-V 与 CPU 内核
- 公司有**两条 CPU 内核路线**：既有 32 位 **XBurst（MIPS 架构）**，与 2014 年起跟进、自研的 **Victory（RISC-V 架构）**
- 自研 **RISC-V CPU 核已应用于部分芯片产品，累计出货量超 1 亿颗**，实现规模化商用
- 公司表述芯片产品正"**全面转向 RISC-V 架构**"，并强调向全自研可控 CPU 核迁移
- ⚠️ **RISC-V 出货"超1亿颗"为累计口径、横跨多产品线**，不等于 RISC-V 专属 AI 芯片收入；公司未单独披露 RISC-V 产品收入

### 核心技术壁垒
1. **车规级存储的认证壁垒**——SRAM/DRAM/NOR Flash/eMMC 进入汽车、工业、医疗客户需长周期认证，切换成本高；长协客户体系是 ISSI 收购带来的核心资产
2. **Fabless + 自研 CPU 内核**——XBurst（MIPS）与 Victory（RISC-V）双内核自研能力，国内少数具备自有指令集内核的设计公司
3. **三线并行（存储+计算+模拟）**——可在车载与工业场景做配套交叉销售，是单纯存储或单纯 SoC 公司不具备的能力
4. **产能锁定**——提前备货 20/18/16nm DDR4/LPDDR4，在存储缺货周期中保障供货

### 主要风险
1. **业绩高度依赖存储价格周期**——存储占营收 66.5%，毛利率 +14.59pct 全部来自涨价；**Q4 价格政策"待定"是最大的不确定性**
2. **涨价驱动而非放量驱动**——计算芯片 +28.69pct 的毛利率提升源于 KGD 缺货涨价（成本推动型提价），可持续性弱于需求驱动
3. **存货与商誉双减值风险**——高价备货库存 + ISSI 收购商誉
4. **估值波动极大**——52 周区间 70.72–279.44 元（近 4 倍），PE(TTM) 约 48，周期股在盈利高点估值失真
5. **RISC-V 叙事与业绩错配**——RISC-V 出货累计 1 亿颗，但未单独披露收入；市场以 RISC-V 标签定价，实际业绩由存储周期决定
6. **上游依赖**——晶圆代工、封测产能紧张，KGD 缺货涨价直接压缩计算芯片成本弹性
7. **与兆易创新的正面竞争**——同为利基存储 + MCU/SoC，产品线与客户高度重叠
