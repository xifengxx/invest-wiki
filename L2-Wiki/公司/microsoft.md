# Microsoft

从自研AI芯片到Copilot应用的全球最强全栈AI帝国——Azure云年收入$750亿且增速高达34%，作为OpenAI独家算力合作伙伴，M365 Copilot正重塑全球数亿企业用户的工作方式。

## 财务状况

|------|--------|--------|--------|-----------|

| 运营利润 | $977亿 | $1094亿 | $1285亿 | **$406亿**（单季，+18% YoY） |

**Azure AI成增长主引擎**：Azure年收入突破$750亿，Q4单季增速高达39%。AI服务已连续多个季度贡献Azure增长的显著份额（约12-13个百分点），预计AI年化收入run rate即将突破$150亿。微软云（含Azure+M365 Commercial+其他）Q4单季收入$467亿，同比+27%，是公司营收最大增长极。

### Q4 FY2026 详情（截至2026.6）

- **Capex**：$410亿（含资本租赁），现金性Capex约$365亿；下季度指引$500亿。FY2026自然年从$190B→$175B是会计调整（资本租赁分类变动），实际指引未变。短周期资产（服务器等）占比从50%拉至2/3+，意味着摊销折旧反噬尚未到来
- **现金流**：经营流入单季$550亿，FCF约$196亿（同比-23%），预计FY2027全年FCF勉强守住
- **新签合同**：单季签$774亿（恢复增长），RPO积压至$6780亿（+$500亿 QoQ），远超当季确认收入$593亿
- **经营利润率**：小幅上扬（未降），智慧云板块经营利润率40.4%同比维稳；靠经营杠杆+裁员降本（财年减员5千至12.3万）
- **生产力板块**：商业M365云+14%，E7定价$99/月（单独买$120的打包折扣），通过做高附加值产品渗透率实现ASP名降实升
- **个人计算**：-5%（好于预期-10%），Windows OEM -7%（预期-15%+），搜索广告+7%（剔汇率+10%）

## 产品线详解

- **Azure AI**：全球第二大公有云，市场份额约24%，提供OpenAI全系列模型（GPT-4o/o3）、自研Phi小模型及AI Foundry一站式开发平台，作为OpenAI**独家算力供应商**构建了不可复制的竞争壁垒
- **M365 Copilot**：深度嵌入Word、Excel、Teams、Outlook等办公套件，按月付费每用户$30，面向全球超4亿商用Office用户群体，是企业级AI变现的标杆模式
- **GitHub Copilot**：开发者AI编程助手，已积累180万+付费用户，牢牢占据AI编码工具赛道第一
- **Dynamics 365 + Copilot**：CRM与ERP系统内置AI代理，季度增速达23%
- **全球数据中心**：覆盖60+Azure区域、超300座数据中心，FY2025资本开支突破$500亿用于AI算力基础设施扩建

### 2026.8.5 Q4 FY2026 更新

**Azure确定性重启加速**：Q4同比+43%（超乐观预期42%），Q1 FY2027指引45%，管理层明确下半年整体比上半年加速。催化因素：(1) OAI 7月GPT 5.6发布带动云用量加速；(2) Github Copilot 6月从月费转向按用量计费；(3) RPO $6780亿提供收入确认储备。

**后OAI时代客户多元化见效**：微软与OAI貌合神离后，Azure增速曾放缓、办公软件AI化落地难产。但本季Azure加速+签单回血（$774亿），说明客户多元化策略开始取得成效。模型/芯片自研虽弱，但增长有力+估值折价（相对同行）+利润率稳+现金流不崩=具备性价比。

**Capex与摊销的错配窗口**：短周期资产（服务器等）占比从50%拉到2/3+，意味着现有Capex转化为折旧的速度快于长周期资产（数据中心建筑），但当前摊销折旧额同比几乎零增，折旧反噬尚未到来。需持续关注短周期资产占比变化对后续利润率的影响。
