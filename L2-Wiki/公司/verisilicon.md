# 芯原股份

国产 AI ASIC 的"卖水人"——营收翻倍、订单已达 2025 全年的 2.5 倍，却仍在亏损。它的报表里最值得读的不是利润表，而是**在手订单 124.49 亿元**和**经营现金流转正**这两个前瞻信号。

## 产品线详解

### 半导体 IP 授权（高毛利基本盘，但增速失速）
六类处理器 IP：**GPU、NPU、VPU、DSP、ISP、Display Processing**，加 **1,700 多个**数模混合 IP、射频 IP 和接口 IP。接口 IP 覆盖 UCIe、USB、MIPI、HDMI、DP/eDP、PCIe、高速 SerDes。

**GPU + NPU + VPU 三类 IP 合计贡献 IP 授权服务收入近 60%**——AI 相关 IP 已成为授权业务的主体。

- **NPU IP 已被 91 家客户用于 140 余款 AI 芯片**，全球累计出货近 2 亿颗；端侧大语言模型推理 NPU 算力达 40+ TOPS
- 22nm FD-SOI 平台：开发 60 多个模拟及数模混合 IP，累计向 46 个客户授权 300 多个/次 FD-SOI IP 核，45 个一站式设计项目中 **36 个已进入量产**
- 累计半导体 IP 授权客户近 **480 家**

### 一站式芯片定制（增长引擎）
- **设计服务**：1H26 收入 3.50 亿元（+50.73%），毛利率 19.29%（2025 年为 14.22%，改善明显）；新增客户 16 家，累计 365 家
- **量产服务**：1H26 收入 11.63 亿元（**+185.29%**），毛利率 16.35%（2025 年 18.14%，略有下滑）；**在手订单中超 100 亿元、超 83% 来自数据处理（主要 AI ASIC）**
- 工艺能力覆盖 **4nm FinFET 到 250nm CMOS**；多个 5nm SoC 一次流片成功并量产，**4nm SoC 项目已成功流片**

### Chiplet 与先进封装
指导方针为「**IP 芯片化（IP as a Chiplet）、芯片平台化（Chiplet as a Platform）、平台生态化（Platform as an Ecosystem）**」。公司是**中国大陆首批加入 UCIe 联盟的企业之一**，依托自研 UCIe 物理层接口 IP 以及 2.5D/CoWoS、3D 堆叠、面板级封装经验，聚焦 **AIGC 大数据处理**与**高端智驾**两大赛道。

### RISC-V
深耕超 7 年，为**中国 RISC-V 产业联盟首任理事长单位**。半导体 IP 已被 14 款芯片采用（覆盖 CPU、GPU、NPU 等核心模块）；已为 **25 家客户的 25 款 RISC-V 芯片**提供一站式定制服务并陆续进入量产。

### 车规与新兴应用
已为某知名新能源汽车厂商提供基于 **5nm 车规工艺的自动驾驶芯片定制**服务并一次流片成功；推出超低能耗 **AI/AR 眼镜 SoC 平台**（双芯片分布式架构、HB-PoP 封装、22 个独立电源域、无 DDR 运行，基于谷歌 Gemma3-270M 轻量模型优化）；芯健康 VeriHealthi 已为全球多家客户提供侵入式脑机接口芯片、胶囊内窥镜芯片 ASIC 定制。
