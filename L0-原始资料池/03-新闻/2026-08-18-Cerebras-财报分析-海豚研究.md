## 指引

### Q3 2026
- Core 营收: $214-216M
- Core 毛利率: 38-40%（预期低点）
- Core 营业利润率: -25% ~ -23%

### 全年 2026（上调）
- Core 营收: $880-890M（从 $855-865M 上调）
- Core 毛利率: 41-43%（从 38-41% 上调）
- Core 营业利润率: -19% ~ -17%

### 2027
- 管理层预期 core 营收再次「翻三倍以上」，长期毛利率目标 >60%

## 需求展望
- 管理层称需求「through the roof」，core 营收/core 毛利率/core 营业利润率均超自身指引
- RPO（剩余履约义务）达 ~$25B，提供多年收入可见性
- 8/13 财报后股价跌 ~11.85%，8/14 再跌 ~5.21%：市场聚焦 GAAP 营收 miss + 大额净亏 + 毛利率压力，即使云收入暴增 + 全年指引上调
