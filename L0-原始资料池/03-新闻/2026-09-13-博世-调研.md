## 博世 MEMS 传感器业务（重点）

### 商业模式优势：IDM 垂直整合
博世是 **IDM（垂直整合制造商）**，覆盖 MEMS 全价值链：`传感器设计 → 工艺开发 → 自有晶圆制造 → 自研 ASIC → 封装/测试 → 系统集成`。**自研 ASIC 能力是关键壁垒**——多数 MEMS 厂商需外购 ASIC。博世亦对外提供 **MEMS 代工服务（foundry service）**。

### 汽车级应用
安全气囊（碰撞后**毫秒级**触发，ASIL B–D）、ESP/车辆动态控制（惯性传感器簇，ASIL D）、ADAS/自动驾驶（6轴IMU SMU300/SMI970，ASIL D）、TPMS（SMP290）、主动悬架、路噪消除RNC、发动机控制、乘员检测/碰撞压力。
> 博世 **1998 年推出首款 ESP 用 MEMS 智能传感器**；其首创的 **"Bosch process"（DRIE 深反应离子刻蚀）** 使垂直硅结构成为可能，是当代 MEMS 制造的基础工艺。

## 关键判断

| 判断 | 依据 |
|------|------|
| **"全球最大 MEMS 供应商"在整体口径成立，单品口径不成立** | Yole 连续多年列博世整体 MEMS 第 1；但**加速度计单品口径下博世排第 3**（ADI 第1、ST 第2）。引用必须标口径 |
| **13–14% 份额是推算值，非 Yole 明示** | $2.0B ÷ $15.4B ≈ 13%；**Yole 从未明示该百分比**，14% 无任何来源支持 |
| IDM 自研 ASIC 是核心壁垒 | 自研 ASIC 与 MEMS 器件协同设计，多数对手需外购；全链条覆盖提升交付安全性与成本控制 |
| MEMS 业务不单独披露，是集团财务的"隐形部分" | 隶属 Mobility 板块下的半导体业务，与汽车电子合并披露；MEMS 全球第 1 但无法从财报直接跟踪 |
| 集团层面正经历严重盈利压力 | FY2025 EBIT 利润率仅 **2.0%**（FY2023 为5.3%），税后**净亏损 −€400M（2009年以来首次）**，重组拨备 €2.7B，FCF 降至约€0.3B |
| AI 化是 MEMS 的下一增长点 | BMI5 平台内置**可编程 Edge-AI 分类引擎**（CES 2026，2026Q3量产出货）；目标 2027 年 90% 产品含集成智能；Yole 指出**每台人形机器人可能用多达15个IMU** |
