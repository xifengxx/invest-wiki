## 关键进展

### IP 组合与工艺能力
- 拥有 **GPU、NPU、VPU、DSP、ISP、Display Processing 六类处理器 IP** + **1,700 多个数模混合/射频/接口 IP**
- 工艺覆盖 **4nm FinFET 到 250nm CMOS**；多个 5nm SoC 一次流片成功并量产，**4nm SoC 项目已成功流片**
- **NPU IP 已被 91 家客户用于 140 余款 AI 芯片**，全球累计出货近 2 亿颗；端侧大模型推理 NPU 算力 40+ TOPS
- 22nm FD-SOI 工艺上开发 60 多个 IP，累计向 46 个客户授权 300 多个/次 FD-SOI IP 核，36 个项目进入量产

### Chiplet
- 方针「**IP 芯片化、芯片平台化、平台生态化**」；中国大陆首批加入 **UCIe 联盟**的企业之一
- 依托自研 UCIe 物理层接口 IP + 2.5D/CoWoS、3D 堆叠、面板级封装经验，聚焦 **AIGC 大数据处理 + 高端智驾**两大赛道

### RISC-V
- 深耕超 7 年，**中国 RISC-V 产业联盟首任理事长单位**
- 半导体 IP 已被 14 款芯片采用；已为 **25 家客户的 25 款 RISC-V 芯片**提供一站式定制服务
- 与 **谷歌**合作开发基于 RISC-V 的超低能耗 Coral NPU IP
- **芯来科技收购已终止**（2025-12-12 公告终止，原拟发股+现金收购 97.0070% 股权）；芯来科技转向独立 IPO，2026-09 启动北交所辅导

### 收购逐点半导体
- 2025-10-15 公告，通过 SPV 天遂芯愿联合共同投资人收购，**对价不超过 9.5 亿元**
- **2026-01-06 完成交割并纳入合并报表**；芯原持有天遂芯愿 **40%** 股权、为单一第一大股东并享有控制权
- 投资方含华芯鼎新（大基金三期载体）、国投先导、亦庄国投旗下等
- 标的 2004 年成立，原为纳斯达克上市公司 Pixelworks 中国控股子公司，拥有 160 多项发明专利；战略意义在于图像前处理 IP 与后处理 IP 结合

### 新方向
- 超低能耗 AI/AR 眼镜 SoC 平台（双芯片分布式架构、HB-PoP 封装、22 个独立电源域、无 DDR 运行，基于谷歌 Gemma3-270M 优化）
- 已为某知名新能源车企提供 **5nm 车规工艺自动驾驶芯片定制**并一次流片成功
- 布局卫星通信、**具身智能**、脑机接口（芯健康 VeriHealthi 已提供侵入式脑机接口芯片、胶囊内窥镜芯片 ASIC）
- 累计半导体 IP 授权客户近 480 家；芯片定制客户累计 365 家
