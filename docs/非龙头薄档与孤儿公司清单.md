## 背景

本文件列出**龙头级以外**的未达标公司，按优先级分类。

## 判据

- **未达标**：YAML 字段 < 20/25，或 body `##` 段 < 5
- **非龙头薄档**：在赛道 YAML 中被引用但角色不是龙头级（如"二线弹性 / 核心参与者 / 概念股"），词条未达标
- **孤儿公司**：有公司页面但不在任何赛道 YAML 的 `companies` 列表中被引用

## 推进建议

1. **修孤儿龙头数据连接**（11 家）：把 ASM International、FormFactor、DuPont、Xilinx、Microchip、Wolfspeed、VAT、MKS、Astera Labs、鸿海精密、ASM Pacific、Horiba、Taiyo Nippon Sanso、ROHM、Fuji Electric、澜起科技挂回对应赛道。这是数据完整性问题，不是内容问题。
2. **按赛道薄档数量从多到少补**：IDC (10) → 自动驾驶 (9) → PCB (7) → 液冷 (7) → 训练平台 (6) → 靶材/光芯片/光模块 (5×3)。每批 3～5 家。
3. **碎片赛道各补 1～2 家**，可与相邻批次合并。
4. **孤儿非龙头最后处理**：先逐家确定该挂回哪个赛道，再补内容。工作量最大但影响相对最低。
