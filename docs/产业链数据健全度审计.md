## 五、判据说明

- **龙头级**：赛道 `companies[].role` 含「龙头 / 第一 / 主导」，或公司 `chain_role == 龙头`
- **全面**：YAML 字段 ≥ 20/25 **且** body `##` 段 ≥ 5
- **中等**：字段 ≥ 20 但段 < 5（数据在，需展开成叙事）
- **薄**：字段 < 20（结构性空缺，需补数据）
- **孤儿**：公司页面存在但赛道 YAML `companies:` 列表中无同名引用
- **健康度**：公司全面率 × 60 + 龙头占比 × 20 + 正文段数 × 4
